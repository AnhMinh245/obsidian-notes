8. High Availability & Scalability – Index

Section này bao gồm các khái niệm nền tảng về khả năng mở rộng hệ thống, Elastic Load Balancing và Auto Scaling Group — ba trụ cột giúp kiến trúc AWS đạt được hiệu năng cao + không downtime.

Danh sách bài

  • 08.1 – Scalability & High Availability — Vertical vs Horizontal Scaling, định nghĩa HA, ứng dụng trên EC2
  • 08.2 – Elastic Load Balancing (ELB) — Tại sao cần LB, Health Check, 4 loại LB, Security Group pattern
  • 08.3 – Application Load Balancer (ALB) — Layer 7 routing, Target Groups, SNI, X-Forwarded headers
  • 08.4 – Network & Gateway Load Balancer (NLB / GWLB) — Layer 4/3, static IP, GENEVE, so sánh 3 loại LB
  • 08.5 – ELB Advanced Features — Sticky Sessions, Cross-Zone LB, SSL Certificates, Connection Draining
  • 08.6 – Auto Scaling Group (ASG) — Launch Template, Scaling Policies, CloudWatch, Cooldown
  • 08.7 – Tại sao ALB phải dùng Target Groups? — Giải thích sâu kiến trúc Target Group
