13.5 – S3 Batch Operations & Storage Lens

Cách đọc note này: Batch Operations = thao tác hàng loạt object; Storage Lens = quan sát (không thao tác). Đừng nhầm hai cái — đề thi hay gài chung một câu hỏi.

S3 Batch Operations

Vấn đề cần giải quyết

Cần thực hiện cùng 1 hành động cho hàng triệu object — không thể làm thủ công từng cái:

  • Encrypt lại hàng triệu object đang unencrypted.
  • Thay đổi tag/ACL hàng loạt.
  • Restore hàng loạt từ Glacier.
  • Invoke Lambda cho từng object.

S3 Batch Operations làm gì?

Chạy 1 job cho rất nhiều object cùng lúc:

Action Mô tả
Copy Copy object sang bucket/storage class khác
Encrypt Mã hóa lại object (SSE-S3 → SSE-KMS)
Restore Restore hàng loạt từ Glacier
Invoke Lambda Xử lý tùy chỉnh từng object
Change Tags Cập nhật tags hàng loạt
Change ACL Cập nhật ACL hàng loạt
Replicate S3 Batch Replication (object cũ)

Nguồn danh sách object

  • S3 Inventory — danh sách object được S3 tự generate định kỳ.
  • Query bằng Amazon Athena — lọc object theo metadata.

AWS quản lý gì?

AWS tự quản lý: retry, progress report, completion notification, failed object list.

Quick reference — dùng Batch Ops khi nào?

Nhu cầu Dùng
Upload file lớn Multipart Upload
Upload từ xa nhanh Transfer Acceleration
Download nhanh Byte-Range Fetch
Trigger xử lý khi upload S3 Event Notification
Xử lý hàng loạt object hiện có Batch Operations
Replicate object cũ Batch Replication

S3 Storage Lens

Storage Lens là gì?

S3 Storage Lens = dịch vụ phân tích & quan sát S3 ở cấp độ toàn tổ chức (Organization-level).

Giúp: Hiểu – Phân tích – Tối ưu S3 trên nhiều accounts, regions, buckets, prefixes.

Storage Lens KHÔNG làm gì

Bạn muốn Dùng công cụ nào
Tự động chuyển storage class Lifecycle Rules
Gợi ý Standard vs IA S3 Analytics
Log từng request S3 Access Logs
Monitoring real-time CloudWatch
Thao tác object hàng loạt Batch Operations

Storage Lens chỉ phân tích & quan sát — không thao tác dữ liệu.

Các nhóm metrics

Metrics Group Phát hiện
Summary StorageBytes, ObjectCount — bucket nào tăng nhanh
Cost-Optimization Incomplete Multipart, Non-current versions — tìm chỗ lãng phí
Data-Protection VersioningEnabled, CRR rules — audit compliance
Activity AllRequests, GetRequests, BytesDownloaded
HTTP Status Code 403 Forbidden, 404 Not Found — debug permission

Free vs Paid

Free Advanced (trả phí)
Metrics ~28 metrics Đầy đủ + prefix-level
Data history 14 ngày 15 tháng
CloudWatch integration ❌ ✔

So sánh: Storage Lens vs S3 Analytics vs CloudWatch

Dịch vụ Mục tiêu
Storage Lens Governance toàn org — multi-account, multi-region
S3 Analytics Gợi ý chuyển Standard ↔ Standard-IA cho từng bucket
CloudWatch Monitoring real-time, alerting
S3 Access Logs Log chi tiết từng request
S3 Inventory Danh sách objects theo lịch

Bảng từ khoá đề thi

Từ khoá trong đề Chọn
"xử lý/mã hoá lại hàng triệu object hiện có" S3 Batch Operations
"cần danh sách object để filter bằng SQL" S3 Inventory + Athena
"quan sát chi phí/compliance toàn tổ chức, nhiều account" S3 Storage Lens
"muốn dữ liệu lịch sử 15 tháng" Storage Lens Advanced (trả phí)
"chỉ cần ~28 metric miễn phí" Storage Lens Free tier

Điểm hay ra thi

  • Batch Operations = giải pháp khi cần xử lý hàng loạt object hiện có.
  • S3 Batch Replication = cách replicate object cũ đã tồn tại trước khi bật Replication Rule.
  • Storage Lens chỉ observe, không thao tác.
  • Cost-Optimization metrics trong Storage Lens giúp phát hiện incomplete Multipart Uploads bị bỏ dở (tốn phí).

Takeaway cá nhân

  • Batch Operations giải quyết vấn đề "làm 1 việc cho N triệu objects" — rất hữu ích cho migration và compliance.
  • Storage Lens là "big picture view" của S3 trên toàn tổ chức — dùng cho governance, không phải operations.
