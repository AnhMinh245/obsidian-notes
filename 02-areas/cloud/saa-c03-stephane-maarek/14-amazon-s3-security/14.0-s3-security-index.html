14. Amazon S3 Security – Index

Section này bao gồm các cơ chế bảo mật nâng cao của S3: mã hóa dữ liệu (at-rest và in-transit), và các tính năng bảo vệ dữ liệu khác.

Danh sách bài

Ghi chú

Section 14 đã được bổ sung đầy đủ (2026-09-13) — toàn bộ topic bên dưới nay nằm trong 14.1, không tách file riêng vì mỗi topic tương đối ngắn:

  • S3 CORS — Cross-Origin Resource Sharing (cho phép web app truy cập S3 từ domain khác)
  • S3 MFA Delete — Yêu cầu MFA khi xóa version hoặc tắt Versioning
  • S3 Access Logs — Log mọi request vào S3 bucket riêng
  • S3 Pre-Signed URLs — URL tạm thời cho phép truy cập object không public
  • S3 Glacier Vault Lock — Compliance lock (WORM) cho Glacier
  • S3 Object Lock — Ngăn xóa/ghi đè object trong thời gian định trước (WORM for S3)
  • S3 Access Points — Đơn giản hóa quản lý access cho bucket lớn
  • S3 Object Lambda — Xử lý object trước khi trả về client (qua Lambda)
