    Q{"❓ Bạn cần<br/>monitor gì?"}

    Q -->|"Dự đoán<br/>tương lai"| FC["🔮 Forecast<br/>Monitor"]
    Q -->|"1 server khác<br/>so với peers"| OL["👥 Outlier<br/>Monitor"]
    Q -->|"Process có<br/>đang chạy?"| PR["⚙️ Process<br/>Monitor"]
    Q -->|"Health check<br/>OK/CRITICAL?"| SC["❤️ Service Check<br/>Monitor"]
    Q -->|"Kết hợp<br/>nhiều điều kiện"| CP["🔗 Composite<br/>Monitor"]

    TH -.-> TH1["Error > 5%<br/>Disk > 90%"]
    AN -.-> AN1["Traffic thấp<br/>bất thường thứ Hai"]
    FC -.-> FC1["Disk đầy<br/>trong 14 ngày"]
    OL -.-> OL1["1/10 servers<br/>CPU cao bất thường"]
    PR -.-> PR1["NGINX process<br/>= 0"]
    SC -.-> SC1["nginx.can_connect<br/>= CRITICAL"]

📋 Journey of a Log

flowchart TD
    E["1️⃣ Emission<br/>App tạo log"] --> I["2️⃣ Ingestion<br/>Agent gửi HTTPS 443"]
    I --> J["3️⃣ JSON Preprocessing<br/>Auto-parse JSON"]
    J --> P["4️⃣ Pipeline Processing<br/>Grok, Remappers"]
    P --> S["5️⃣ Standard Attributes<br/>Chuẩn hoá names"]
    S --> SD["6️⃣ Sensitive Data Scanner<br/>Redact PII ⚠️ Optional"]
    SD --> SR["7️⃣ Security Rules<br/>SIEM detection"]
    SR --> ET["8️⃣ Error Tracking<br/>Nhóm errors"]
    ET --> AD["9️⃣ Anomaly Detection<br/>ML patterns"]
    AD --> R{"🔟 Routing"}

    R -->|Bắt buộc| LT["▶️ Live Tail<br/>Free, realtime"]
    R -->|Optional| GM["📊 Generate Metrics"]
    R -->|Tính phí| IDX["🗄️ Indexes<br/>Searchable 15d"]
    R -->|Lưu lâu| LF["📦 Log Forwarding<br/>S3, GCS, Splunk"]
    R -->|Security| SIEM["🛡️ Cloud SIEM"]
