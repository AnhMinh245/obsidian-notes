🧠 Phương Pháp Học Datadog Fundamentals Hiệu Quả

Vấn đề: 10 files, 750+ dòng kiến thức → đọc thụ động = quên 80% sau 1 ngày.

Giải pháp: Học chủ động (Active Recall + Spaced Repetition) + chia nhỏ sessions.

⏱️ Nguyên Tắc Vàng: “30-5-5”

30 phút ĐỌC  → 5 phút TỰ KIỂM TRA → 5 phút NGHỈ
                (đóng tài liệu, tự hỏi mình nhớ gì)

★ Không đọc quá 30 phút liên tục — não bắt đầu "lựa chọn" bỏ qua thông tin.
★ Tổng: 3-4 sessions/ngày (2-2.5 giờ) là tối ưu. KHÔNG cần học 8 tiếng/ngày.
★ Sáng học mới → Tối review lại bằng FAQ.

🎯 4 Kỹ Thuật Học Chủ Động

1. 🔄 FAQ-First (Đọc câu hỏi TRƯỚC)

ĐỪNG đọc từ đầu file!

Bước 1: Kéo xuống cuối file → đọc phần "Câu Hỏi Thường Gặp"
Bước 2: Tự cố trả lời TRƯỚC KHI đọc đáp án
Bước 3: Câu nào không trả lời được → quay lên đọc phần liên quan
Bước 4: Quay lại FAQ → trả lời lại

★ Tại sao hiệu quả?
  Não hoạt động tốt hơn khi có "câu hỏi cần giải đáp" (curiosity gap)
  Thay vì "đọc 500 dòng" → "tìm đáp án 15 câu hỏi" (có mục tiêu rõ ràng)

2. 🗣️ Teach-Back (Giải thích cho người khác)

Sau mỗi session 30 phút:
  Đóng tài liệu → giả vờ giải thích cho đồng nghiệp:

  "Datadog Agent có 3 thành phần chính..."
  "Anomaly Monitor khác Threshold Monitor vì..."
  "Journey of a Log gồm 10 bước, đầu tiên là..."

★ Nếu bạn không giải thích được = bạn chưa hiểu
★ Chỗ nào "ờ... hình như là..." = cần đọc lại
★ Có thể nói thành tiếng hoặc viết ra giấy

3. 📝 Flashcard từ Exam Tips

Mỗi file có các "★ Exam tip" — biến chúng thành flashcards:

MẶT TRƯỚC:                    MẶT SAU:
┌─────────────────────┐       ┌─────────────────────────┐
│ "Globally accurate   │       │ Distribution            │
│  percentiles"        │       │ (không phải Histogram)  │
│  → Dùng metric       │       │                         │
│  type nào?           │       │                         │
└─────────────────────┘       └─────────────────────────┘

★ Dùng Anki hoặc viết tay đều OK
★ Tập trung vào keyword table trong file 10 (10.8)
★ ~40 flashcards là đủ cho toàn bộ bộ tài liệu

4. 🗺️ Mind Map cho mỗi file

Sau khi đọc xong 1 file, vẽ mind map 1 trang:

                    ┌─ Collector (15s)
     ┌─ Components ─┤─ Forwarder (443)
     │              └─ DogStatsD (8125)
     │
AGENT├─ Commands ─── status > check > configcheck > flare
     │
     ├─ Troubleshooting ─── status → check → logs → flare
     │
     └─ Autodiscovery ─── Labels / Annotations → template

★ 1 file = 1 trang A4 mind map
★ Vẽ TAY (không đánh máy) → nhớ tốt hơn 2-3x
★ Dán lên tường phòng làm việc → passive review

🏆 Chiến Lược Ưu Tiên (Nếu Thiếu Thời Gian)

Nếu chỉ có 3 ngày, tập trung vào 3 files ★★★★★:

NGÀY 1: 02_datadog_agent.md      (~20% đề thi)
NGÀY 2: 04_metrics_timeseries.md  (~15% đề thi)
        07_monitors_alerts.md     (~15% đề thi)
NGÀY 3: Top 38 Must-Know (file 10) + Practice Exam

★ 3 files này chiếm ~50% đề thi!
★ Top 38 cover thêm ~20% từ các files khác
★ Qua được 70% → gần pass (75%)

📊 Self-Assessment Checklist

Trước khi thi, bạn phải trả lời được TẤT CẢ câu dưới đây không cần tài liệu:

Must-pass (trả lời sai = likely fail)

  • 3 components của Agent là gì? Port nào?
  • 5 metric types + khác biệt Histogram vs Distribution?
  • 3 UST tags?
  • 5 monitor types + khi nào dùng từng loại?
  • Journey of a Log (ít nhất 5/10 bước)?
  • Logging Without Limits = gì?
  • API Key vs Application Key?

Should-pass (trả lời đúng = comfortable pass)

  • Default states của Agent components?
  • 3 loại Integration?
  • Metric query 5 thành phần?
  • Timeboard vs Screenboard?
  • SLO/SLI/SLA/Error Budget chain?
  • DogStatsD flush interval + wire format?
  • Agent Flare dùng khi nào?
  • Process Monitor vs Service Check Monitor?
  • Facet vs Attribute?

Bonus (trả lời đúng = high score)

  • Anomaly: 3 algorithms (Basic/Agile/Robust)?
  • Hostname resolution priority order?
  • Dual Shipping config?
  • Sample rate trong DogStatsD?
  • Outlier: DBSCAN vs MAD?

💡 Tóm lại: Đừng đọc — hãy hỏi và trả lời. Mỗi ngày 1-1.5 giờ, 10 ngày là sẵn sàng thi.
