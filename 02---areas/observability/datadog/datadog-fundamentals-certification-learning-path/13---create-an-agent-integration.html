Phần 1: Giới thiệu chung

Integrations (tiện ích tích hợp) cho phép bạn thu thập dữ liệu trên các service cụ thể bằng Datadog. Bạn có thể dùng Integrations để tập hợp metrics và logs từ cơ sở hạ tầng và các ứng dụng vào Datadog, nhằm có cái nhìn toàn cảnh về toàn bộ hệ thống.

Mặc dù Datadog đã có sẵn thư viện với hơn 400 integrations mặc định, nhưng nếu bạn đang phát hành một service của riêng mình và muốn tích hợp với Datadog, hoặc muốn có một custom integration riêng biệt, bạn hoàn toàn có thể tự xây dựng nó!

Trong khóa học này, bạn sẽ phát triển một custom Agent Check Integration.

1.1. Các loại Integration trong Datadog

Datadog cung cấp 3 loại integration chính:

Loại IntegrationMô tảVí dụ
Agent-basedĐược cài đặt cùng Datadog Agent, sử dụng một class method của Python gọi là check để định nghĩa các metric cần thu thập.Custom Agent Checks
Authentication (crawler) basedThiết lập trên UI của Datadog, bạn cung cấp credentials để Datadog dùng API gọi đến hệ thống bên thứ ba lấy metrics.Slack, AWS, Azure, PagerDuty
LibraryDùng Datadog API để giám sát ứng dụng dựa trên ngôn ngữ lập trình của ứng dụng đó.Node.js, Python

Phần 2: Quy trình xây dựng một Integration

Custom Checks là một cách gọn nhẹ để thêm chức năng cho Datadog Agent — phù hợp để báo cáo định kỳ (occasional reporting) hoặc những dữ liệu bị giới hạn. Tuy nhiên, với các use case phổ biến hơn như application frameworks, open source projects, bạn nên viết một integration.

Sau khi viết xong, bạn có thể submit integration để được đưa vào kho lưu trữ (repository) của cộng đồng. Khi đã được duyệt, Datadog sẽ không tính các metrics từ integration đó là custom metrics nữa. Việc này giúp giảm rào cản áp dụng, khuyến khích mọi người dùng sản phẩm/dự án của bạn và tăng độ nhận diện trong hệ sinh thái Datadog.

2.1. Quá trình phát triển

Mục tiêu ban đầu là viết code thu thập metric một cách đáng tin cậy và đảm bảo framework tổng thể đã sẵn sàng. Bạn sẽ bắt đầu bằng cách viết một chức năng cơ bản dạng Custom Check, sau đó điền các chi tiết framework theo tài liệu Build an out-of-the-box integrations.

Một integration package hoàn chỉnh bao gồm:

  • Code để thu thập metrics
  • Unit tests
  • Integration tests
  • Các file hỗ trợ (assets, configuration, manifest…)

2.2. Các loại Repository để xuất bản (Publish)

3.4. Viết Integration Tests

BẢNG SO SÁNH: Unit Tests vs Integration Tests

Tiêu chíUnit TestsIntegration Tests
Mục đíchKiểm tra các thành phần (unit) code đơn lẻ, độc lập.Kiểm tra xem các thành phần làm việc với nhau và với external service như thế nào (tổng thể end-to-end).
Độ phức tạpNhẹ, dễ viết, chạy rất nhanh.Phức tạp hơn, cần tạo môi trường giả lập (fixtures/Docker).

4.2. Các file cấu hình bắt buộc

FileMục đích và Vai trò
spec.yamlĐịnh nghĩa cấu trúc cấu hình chuẩn. Dùng làm khuôn (template) để ddev tự động sinh ra conf.yaml.example. Đảm bảo tính nhất quán trên toàn hệ sinh thái Datadog.
conf.yaml.exampleFile mẫu hướng dẫn người dùng cấu hình integration. Khi cài đặt, người dùng đổi tên thành conf.yaml, điền tham số (như url, search_string) để Agent chạy.
manifest.jsonKhai báo metadata (tên hiển thị, danh mục, tags, hệ điều hành). Dùng để hiển thị integration trên trang Datadog UI hoặc Marketplace.
service_checks.jsonKhai báo các trạng thái check có thể báo cáo (OK, WARN, CRIT). Khớp với hàm self.service_check().
metadata.csvKhai báo toàn bộ metric mà integration có thể sinh ra (tên metric, loại, đơn vị). Nếu integration không sinh metric thì bỏ qua file này.

Phần 5: Build và Cài đặt (Build and Install)

Bây giờ code và các file hỗ trợ đã xong, bước cuối là đóng gói (build) integration và cài đặt nó lên Datadog Agent.

5.1. Cài đặt Datadog Agent trên Lab VM

  1. Đăng nhập vào Datadog bằng thông tin tài khoản dùng thử của lab.
  2. Từ menu Datadog (góc dưới bên trái), chọn Agent Installation.
  3. Chọn Linux (vì lab đang chạy Ubuntu).
  4. Lấy mã lệnh cài đặt 1-dòng (chứa sẵn API key của bạn).
  5. Paste vào Terminal để chạy.
  6. Khi cài xong, kiểm tra trạng thái Agent: Bạn sẽ thấy output báo Status: Running.

5.2. Build the wheel (tạo package)

“Wheel” (.whl) là định dạng package chuẩn của Python (tương tự như RPM hay Deb). Công cụ ddev sẽ tự động build wheel cho bạn:

Lệnh này sẽ hiển thị đường dẫn chứa file wheel vừa build. Thử xem danh sách file trong đường dẫn đó:

Bạn sẽ thấy file datadog_awesome-1.0.0-py3-none-any.whl.
File wheel thực chất là một file zip. Bạn có thể kiểm tra ruột của nó bằng unzip -l. Bạn sẽ thấy nó chỉ còn chứa khoảng 12 file (code, config mẫu), gọn hơn rất nhiều so với 33 file trong thư mục development ban đầu.

5.5. Xem Check Summary trên Datadog UI

Vào Monitoring > Check Summary trên Datadog UI.

Tìm awesome.search trong danh sách. Click vào đó, bạn sẽ thấy trạng thái đang là OK. (Nghĩa là trang example.com đang có chứa chữ “Example Domain”).

5.6. Thiết lập Dashboard

Cuối cùng, hiển thị check này lên Dashboard:

  1. Vào Dashboard List > New Dashboard.
  2. Đặt tên Dashboard tùy ý.
  3. Trong panel Widgets bên trái, tìm chữ check status rồi kéo widget Check Status vào dashboard.
  4. Ở phần Check name, chọn awesome.search.
  5. Ở phần Scoping, set Statuses for thành A Cluster of Checks.
  6. Lưu lại.

Bạn sẽ thấy widget hiển thị nền xanh với con số 1 (1 check đang OK).

Nhắc lại: Bài check này kiểm tra http://example.com/ xem có chữ “Example Domain” không. Vì url và chuỗi tìm kiếm đều là biến cấu hình được (trong conf.yaml), bạn hoàn toàn có thể dùng integration này để tìm kiếm bất kỳ chuỗi nào trên bất kỳ website nào!

Phần 6: Tổng kết Lab và Khóa học

Chúc mừng bạn đã hoàn thành khóa học Create an Agent Integration!

Bạn đã đi một chặng đường dài từ:

  • Thiết lập môi trường phát triển với ddev.
  • Viết code Check class (check.py).
  • Xây dựng Unit test và Integration test cho Check của mình.
  • Viết các file cấu hình và assets bắt buộc (spec.yaml, manifest.json, v.v.).
  • Đóng gói code thành file Wheel (.whl).
  • Cài đặt wheel vào Datadog Agent và đưa dữ liệu lên Dashboard.

Việc tự xây dựng Integration là cách tuyệt vời nhất để đưa các dữ liệu đặc thù của bạn vào Datadog. Bằng cách công bố chúng ở “extras” hoặc “marketplace”, bạn có thể chia sẻ tiện ích này với cả thế giới.
