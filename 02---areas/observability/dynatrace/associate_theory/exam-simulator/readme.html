Exam Simulator — Hướng dẫn sử dụng

Browser-based quiz để luyện thi Dynatrace Associate từ dump trắc nghiệm 15 - Exam Dump - Practice Questions. Chạy hoàn toàn offline trong browser (giao thức file://), không cần server.

1. Mở nhanh

Double-click index.html (hoặc kéo thả vào tab browser).

  • Chrome / Edge / Brave / Firefox đều OK.
  • Không cần npm/python để dùng. Chỉ cần khi regenerate câu hỏi từ MD nguồn.

2. Cấu trúc folder

exam-simulator/
├── index.html       # quiz app (HTML + CSS + JS inline, zero dependency)
├── questions.js     # window.QUESTIONS = [...] — load qua <script src>
├── questions.json   # cùng dữ liệu, dạng JSON thuần (debug / version control)
├── parse.py         # parser: MD → JSON + JS
└── README.md        # file này

3. Tính năng

  • Practice mode: chọn đáp án → bấm Xác nhận → đỏ/xanh ngay + giải thích chi tiết + ref về note lý thuyết tương ứng.
  • Shuffle câu hỏi (mặc định bật) — mỗi lần làm thứ tự khác nhau, tránh nhớ vẹt theo thứ tự.
  • Shuffle options (mặc định tắt — vì giải thích nhiều khi nhắc letter cụ thể).
  • Phạm vi: làm tất cả 65 câu, hoặc 10 / 20 / 40 câu đầu của pool đã shuffle, hoặc chỉ câu từng sai (lưu trong localStorage).
  • Multi-choice tự động phát hiện (câu có 2+ đáp án đúng → render checkbox; ngược lại → radio).
  • Wrong tracking: mỗi câu trả lời sai được thêm vào localStorage; khi trả lời đúng lần sau thì tự động remove.
  • Export câu sai → Markdown: ở screen kết quả, bấm Export câu sai → Markdown để dump các câu sai trong phiên này ra MD; paste vào Obsidian để review riêng.
  • Làm lại chỉ câu sai trong lần này: giữ pool ngắn lại đúng các câu vừa miss → drill nhanh.

4. Phím tắt (khi đang làm bài)

PhímTác dụng
1–9Toggle option thứ N
EnterXác nhận (nếu chưa confirm) hoặc Câu tiếp (nếu đã confirm)
EscThoát về trang chính (có confirm)

5. Regenerate câu hỏi khi MD nguồn thay đổi

Sau khi sửa 15 - Exam Dump - Practice Questions (thêm câu mới, sửa đáp án, …):

Parser sẽ:

  1. Đọc ..\15 - Exam Dump - Practice Questions.md (đường dẫn mặc định).
  2. Parse từng câu Q1–Q67 (skip section 13 — hands-on lab).
  3. Ghi questions.json + questions.js.
  4. Skip câu không có options (Q47, Q48 hiện tại — free-response, không phải MCQ).
  5. In summary: số câu theo chủ đề, single vs multi, warnings nếu có.

6. Định dạng nguồn parser nhận

Parser dựa vào pattern markdown của file dump:

  • Section heading: ## <số>. <tên> — section 13 sẽ bị skip.
  • Câu hỏi: ### Q<số>. <tiêu đề> → dòng tiếp theo là prompt.
  • Options (2 biến thể):
    • Letter style: - a. text, - b. text, …
    • Bullet style: - text (không có letter, gán key tự động 1, 2, 3, …).
  • Đáp án trong callout > [!TIP]-:
    • Mỗi dòng > ✅ **A. text** hoặc > ❌ **B. text**.
    • Bullet-style: > ✅ **text** (text khớp với option).
    • Cho phép nhiều đáp án trên cùng dòng: > ✅ **A. ...**, **B. ...**, **C. ...**.
  • Ref: > 📖 Ref: [[<note>#<heading>]] | [[<note2>]].

Nếu thêm câu mới mà parser skip / sai đáp án → mở parse.py, regex ANSWER_LINE_RE và logic validate() là entry-point để debug.

7. Reset / xoá dữ liệu lưu

  • Xoá danh sách câu sai lưu trữ: ở trang Settings → bấm Xoá danh sách câu sai đã lưu, hoặc DevTools → Application → Local Storage → key dt_exam_wrong_qids_v1 → delete.
  • Lưu ý: localStorage gắn theo origin. Mở qua file:// riêng cho mỗi file path, mở qua http://localhost lại là origin khác.

8. Troubleshooting

Triệu chứngNguyên nhân & cách xử
”Lỗi tải dữ liệu — chưa tìm thấy questions.js”Chưa chạy py parse.py lần đầu. Chạy lệnh trên.
Browser block JS / cảnh báo bảo mậtMột số browser cấu hình quá chặt với file://. Workaround: mở qua local server: py -m http.server 8000 trong folder rồi truy cập http://localhost:8000/.
Câu mới thêm vào MD không xuất hiệnQuên regenerate. Chạy lại py parse.py.
Sai đáp án ở câu nào đóSo sánh questions.json với MD nguồn → nếu lệch → fix MD (đáp án trong callout > [!TIP]-) → regenerate.

9. Roadmap (tính năng có thể thêm khi cần)

  • Timer 90 phút giả lập exam thật.
  • Filter theo chủ đề (làm riêng RUM / Synthetic / K8s …).
  • Lưu lịch sử nhiều lần làm + biểu đồ tiến độ.
  • Link obsidian:// từ ref note → mở thẳng trong Obsidian.
  • Anki deck export (.apkg) cho memorization SRS.

Khi muốn bổ sung, sửa index.html (JS state machine ở state object và screen render functions) hoặc nhờ AI agent.
