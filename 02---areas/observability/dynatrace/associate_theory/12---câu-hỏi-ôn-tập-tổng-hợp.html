Chương 12: Câu Hỏi Ôn Tập Tổng Hợp

NOTE

60 câu hỏi chọn lọc từ 2 bộ đề thi, sắp xếp theo chủ đề. Che đáp án → tự trả lời → so sánh. Mỗi câu có link đến chương liên quan để bạn ôn lại ngay nếu sai.

TIP

Cách dùng: Nếu sai > 12 câu (>20%) → ôn lại chương tương ứng. Nếu đúng ≥ 48/60 (≥80%) → bạn sẵn sàng thi.

A: Architecture (8 câu) — 01 - Kiến trúc Dynatrace

A1. Thứ tự data flow trong Dynatrace?

✅ OneAgent → (ActiveGate) → OpenPipeline → Grail → Davis AI / DQL
📖 01 - Kiến trúc Dynatrace > 1. Data Flow

A2. OneAgent mode nào cho database server?

✅ Infrastructure + Discovery — DB là external service, không cần full-stack/code-level APM
📖 01 - Kiến trúc Dynatrace > 2.3 Ba Monitoring Modes + Cloud-Native Full-Stack

A3. Tắt auto-update OneAgent?

✅ Globally cho tất cả HOẶC per host riêng lẻ
📖 01 - Kiến trúc Dynatrace > 2.5 Quản Lý OneAgent

A4. ActiveGate chức năng chính? (multi-select)

✅ Entry point sealed networks + Buffering/compression
❌ Authentication OneAgent requests → SAI
📖 01 - Kiến trúc Dynatrace > 3. ActiveGate

A5. Cluster AG dùng cho deployment nào?

✅ Managed only — SaaS KHÔNG cần
📖 01 - Kiến trúc Dynatrace > 3.2 Hai Loại ActiveGate

A6. OpenPipeline thực hiện gì?

✅ Ingest + real-time processing (6 chức năng: mask, enrich, normalize, extract, route, filter)
❌ “Chỉ routing” → SAI
📖 01 - Kiến trúc Dynatrace > 5. OpenPipeline

A7. Grail query/analytics hiện đại dựa trên gì?

✅ MPP analytics trên Grail, không phụ thuộc inverted index kiểu cũ
📖 01 - Kiến trúc Dynatrace > 4.2 Ba Đặc Tính

A8. Process Group là gì?

✅ Processes cùng technology, cùng task, có thể chạy trên một hoặc nhiều hosts
📖 01 - Kiến trúc Dynatrace > 6.4 Process Group

B: Davis AI & Problems (8 câu) — 02 - Davis AI và Problem Detection

B1. Loại AI nào cho deterministic root cause?

✅ Causal AI — fault-tree trên Smartscape
📖 02 - Davis AI và Problem Detection > 1.1 Causal AI

B2. Khi nhiều anomaly liên quan?

✅ Consolidate → 1 Problem, phân biệt root cause vs impact
📖 02 - Davis AI và Problem Detection > 1.1 Causal AI

B3. Event type severity thấp nhất?

✅ Info events
📖 02 - Davis AI và Problem Detection > 3.1 Event Categories

B4. Event categories đầy đủ?

✅ monitoring unavailable, availability, error, slowdown, resource, custom, info (7 loại)
❌ critical, availability, error, slowdown, resource, warning, custom, info → SAI (thừa critical + warning)
📖 02 - Davis AI và Problem Detection > 3.1 Event Categories

B5. “Unexpected” có phải problem severity?

❌ KHÔNG — không trong danh sách
📖 02 - Davis AI và Problem Detection > 3.1 Event Categories

B6. Davis dùng static thresholds mặc định?

❌ KHÔNG — dùng dynamic baselines
📖 02 - Davis AI và Problem Detection > 2. Dynamic Baselines

B7. Maintenance window có mấy options?

✅ 3: Detect+Alert, Detect but Don’t Alert, Disable Detection
📖 02 - Davis AI và Problem Detection > 7. Maintenance Windows

B8. Traffic alerts cần app chạy bao lâu?

✅ 1 tuần đầy đủ
📖 02 - Davis AI và Problem Detection > 8. Traffic Anomaly Detection

B9. Response time degradation evaluate bằng gì?

✅ Sliding 5 minute time intervals
📖 02 - Davis AI và Problem Detection > 4. Problem Detection

C: RUM (10 câu) — 03 - Digital Experience - RUM

C1. OneAgent cung cấp RUM cách nào?

✅ Inject JavaScript tag vào HTML
📖 03 - Digital Experience - RUM > 1. RUM Trong Bức Tranh Tổng Thể

C2. Cấu trúc RUM đúng?

✅ Application → User Sessions → User Actions
📖 03 - Digital Experience - RUM > 3. Cấu Trúc RUM

C3. Session kết thúc khi nào? (multi-select)

✅ 30 phút inactive, 6 giờ tối đa, khoảng 200 actions/session
❌ “Closing application” → KHÔNG phải cách trả lời chuẩn theo docs hiện tại
📖 03 - Digital Experience - RUM > 4.1 Session Lifecycle

C4. User xóa cookies giữa session?

✅ Thường dẫn tới session mới ở lượt tương tác kế tiếp
📖 03 - Digital Experience - RUM > 4.2 Xóa Cookies

C5. Response time = 3T → Apdex?

✅ Tolerating (T ≤ 3T < 4T)
📖 03 - Digital Experience - RUM > 6. Apdex Score

C6. Set Apdex riêng cho 1 action?

✅ Key User Action → edit settings
📖 03 - Digital Experience - RUM > 6.3 Custom Apdex

C7. Action vừa conversion goal vừa key user action?

✅ Yes
📖 03 - Digital Experience - RUM > 7. Key User Actions

C8. Track checkout completion?

✅ Conversion Goal
📖 03 - Digital Experience - RUM > 7. Key User Actions

C9. Visually Complete?

✅ Tất cả visible elements 100% loaded + rendered
📖 03 - Digital Experience - RUM > 9. Key Performance Metrics

C10. Application baselining dimensions?

✅ Geolocation, User action, Browser, OS
❌ Tags, Conversions
📖 03 - Digital Experience - RUM > 9. Application Baselining

D: Synthetic (12 câu) — 04 - Digital Experience - Synthetic

D1. Browser nào?

✅ Chromium-based browser engine (kiểu trả lời exam: Chrome/Chromium)
📖 04 - Digital Experience - Synthetic > 1.2 Browser Engine

D2. Monitor internal app?

✅ Private Synthetic trên Environment AG
📖 04 - Digital Experience - Synthetic > 2.2 Monitor Internal Applications

D3. Ensure element loaded?

✅ Content validation rule
📖 04 - Digital Experience - Synthetic > 4.1 Content Validation

D4. Chờ 24h trước adjust thresholds?

✅ Performance data averaged over 24h → reference point
📖 04 - Digital Experience - Synthetic > 4.3 Performance Thresholds

D5. CI/CD synthetic integration?

✅ On-demand execution
❌ Private synthetic location, Credential Vault, HTTP Monitor
📖 04 - Digital Experience - Synthetic > 7.2 CI/CD Integration

D6. “Visually Complete” metric?

✅ When all elements visible to user on webpage 100% loaded and rendered
❌ “Largest element rendered” → đó là LCP
📖 04 - Digital Experience - Synthetic > 6.1 Key Performance Metrics

D7. “Session Replay” là gì?

✅ Capture and visually replay complete digital experience of every user, similar to video
❌ “Function of synthetic tests to play back recorded tests locally” → SAI (đó là local playback)
📖 04 - Digital Experience - Synthetic > 9. Session Replay

D8. Issues synthetic detect? (MC)

✅ Availability + Performance
❌ Resource, Application Security
📖 04 - Digital Experience - Synthetic > 7.1 Types of Issues Synthetic Detects

D9. Maintenance window + synthetic overlap?

✅ Maintenance Window → tránh false alerts
❌ Delete monitors, On-demand execution, Credential Vault
📖 04 - Digital Experience - Synthetic > 10. Tình Huống Giả Định

D10. Global network of Synthetic locations?

✅ Public Synthetics
❌ Private Synthetics, Dynatrace Apps, Synthetic On-demand execution
📖 04 - Digital Experience - Synthetic > 2.3 Public Synthetics

D11. Simulate user loading single webpage?

✅ Single-URL browser monitor
❌ HTTP Monitor, Ping test, Browser Clickpath
📖 04 - Digital Experience - Synthetic > 1.1 Comparison Matrix

D12. Performance problem trigger rule?

✅ Threshold violated in 3 of 5 most recent executions at same location
📖 04 - Digital Experience - Synthetic > 4.3 Performance Thresholds

📖 05 - Services và Database Monitoring > 5.2 Span

F1. Separate entities + authorized users?

✅ Management Zones
📖 06 - Configuration và Management > 1. Management Zones vs Host Groups

F2. Tags vs Metadata nguồn gốc?

✅ Tags = manual/rules. Metadata = auto-detected

✅ Values masked

✅ 3

📖 09 - Security và Automation > 2.3 Workflow Owner & Permissions

✅ Run DQL query

✅ Workflows, Scheduling, Business Calendar, Connections
❌ Extensions, Dashboards → KHÔNG thuộc AutomationEngine
📖 09 - Security và Automation > 2.5 AutomationEngine

K4. Workflow trigger types? (multi-select)

L: Dashboards & Notebooks (3 câu) — 07 - Data Analysis và Tools > 4. Notebooks vs Dashboards

L1. Retain DQL query results cho later review? Dùng tool nào?

✅ Notebooks — results saved as snapshot
❌ Dashboards → real-time, results change on each view
📖 07 - Data Analysis và Tools > 4.1 So Sánh Chi Tiết

L2. Dashboard tile types? (multi-select)

✅ Data tile (DQL query), Markdown tile, Code tile
📖 07 - Data Analysis và Tools > 4.2 Dashboard Tiles

L3. Khi nào dùng Notebooks vs Dashboards?

✅ Notebooks: investigation, postmortem, deep-dive analysis (retained data)
✅ Dashboards: real-time monitoring, status board, TV screen (live queries)
📖 07 - Data Analysis và Tools > 4.1 So Sánh Chi Tiết
