Q1. OneAgent modes cho database server

To ensure efficient use of OneAgent monitoring, which modes are recommended for a database server?

Chọn tất cả đáp án đúng (Select all that apply):

  • a. Fullstack
  • b. Infrastructure
  • c. Half stack
  • d. Discovery
  • e. Full support

💡 Đáp án & Giải thích

❌ A. Fullstack
✅ B. Infrastructure
❌ C. Half stack
✅ D. Discovery
❌ E. Full support

Database server là external service — Dynatrace monitor DB bằng cách capture SQL queries từ phía caller (app server). Trên DB host chỉ cần host metrics (CPU, RAM, disk I/O), không cần deep code-level tracing → Infrastructure hoặc Discovery mode là đủ. Full-stack trên DB server = lãng phí resource. “Half stack” và “Full support” không tồn tại.

📖 Ref: 01 - Kiến trúc Dynatrace > 2.3 Ba Monitoring Modes + Cloud-Native Full-Stack ⭐

13. Phần THỰC HÀNH — Hands-on Lab Questions

Các câu thực hành từ verified dump. Đây là hướng dẫn ngắn gọn cho từng câu lab trong bài thi.

Lab Q1. Tạo dashboard kiểu List

Lưu ý đặt đúng tên dashboard, thêm kiểu variable rồi chọn Definition dạng List.

Lab Q2. Dashboard tính sum memory của các Host

Đặt đúng tên dashboard → Chọn metric dt.host.memory.usage → Chọn đơn vị tính là sum → Run query để ra dữ liệu.

Lab Q3. Fetch log tính số lượng log ERROR

Thêm dashboard dạng DQL → Gõ câu lệnh DQL → Run để ra kết quả.

Lab Q4. Mask key user action

Search tool Web trên Dynatrace → Chọn My Web Application → Tìm user action loading of page /login trong top user action → Click chọn user action đó → Chọn Mask key user action.

Lab Q5. Tìm log đúng nội dung

Truy cập Logs and Events → Filter Content là Logging in → Chọn Open With… → Chọn Notebook → New Notebook → Đặt đúng tên như đề bài yêu cầu → Thêm fields như các trường mà đề bài yêu cầu.

Lab Q6. Vẽ biểu đồ dạng Pie Chart

Chọn Notebooks → Tạo New Notebook → Đặt tên Notebook → Gõ câu lệnh đề bài cho → Run → Chọn biểu đồ dạng Pie Chart.

Lab Q7. Tạo workflow send email mỗi 30 phút

Truy cập Workflow → Tạo new workflow → Chọn Schedule mỗi 30 phút → Thêm task send email → Điền to email, Subject, Message như đề bài yêu cầu.
⚠️ Lưu ý: Nhấn Deploy để save workflow.

Lab Q8. Tile Dashboard

Truy cập Dashboard → Tạo mới dashboard → Đặt tên theo yêu cầu → Thêm 3 dashboard tiles: Markdown, Code, Logs như yêu cầu vào.

Lab Q9. Tìm database mà request call tới

Đáp án: TradeManagement.
Cách tìm: Truy cập Distributed Trace → Chọn filter theo endpoint/request → Điền request theo đề bài (ví dụ /v1/easytrade/sell) → Click vào request tìm được → Chọn Service Flow → Nhìn xem DB mà nó call là DB nào → Chọn đáp án đúng.
