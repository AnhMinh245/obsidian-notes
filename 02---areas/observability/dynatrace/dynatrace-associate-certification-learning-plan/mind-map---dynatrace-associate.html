#Tip
1DB monitoring → từ APP SERVER
2Session Replay = Reconstruct ≠ Record
3Baselines 50% deviation default
4Host Group set khi install OneAgent
5Tags KHÔNG restrict access
6Metrics dùng timeseries không fetch
7Synthetics KHÔNG cần OneAgent
8Problem types: A-E-S-R-C
9Apdex: 0-3s / 3-15s / >15s
