﻿# Associate Certification Learning Path — Tổng Hợp & Tham Khảo

Tài liệu này tổng hợp toàn bộ nội dung Dynatrace Associate Certification Learning Path — bao gồm thông tin thi, prerequisites, và tóm tắt kiến thức theo từng module với links tham khảo.

Prerequisites

  • Hiểu SOA (Service Oriented Architecture)
  • Quen thuộc Application Servers (WebSphere, Tomcat, IIS…)
  • Kiến thức web/mobile app architecture (databases, networks, processes)
  • Hiểu application performance metrics
  • Quen OS: Windows, Linux, VMware
  • Hiểu Cloud/Container: AWS, Docker, Kubernetes, OpenShift
  • Khuyến nghị: 6 tháng kinh nghiệm sử dụng Dynatrace

Tổng Hợp Modules

Module 1: The Dynatrace Platform

Kiến thức cần nắm:

  • Dynatrace = unified observability + security + automation platform
  • SaaS model (cloud-based, browser access)
  • 4 pillars: Observability, Security, Automation, Integration
  • Dynatrace Web UI navigation

Docs tham khảo:

  • What is Dynatrace?
  • Navigate the Dynatrace Platform

Module 2: Monitoring & Infrastructure Observability

Kiến thức cần nắm:

  • OneAgent: data collector, auto-instrumentation
  • 3 Monitoring modes: Full-Stack > Infrastructure Only > Discovery
  • Smartscape: 5 layers (D-H-P-S-A)
  • Process vs Process Group
  • Database monitoring: từ app server (caller), không phải DB server
  • Kubernetes monitoring: Operator, pods, nodes, clusters

Docs tham khảo:

  • Infrastructure Observability
  • Dynatrace OneAgent
  • Kubernetes Monitoring
  • Dynatrace Apps
  • Improve Database Performance

Module 3: Notebooks & Dashboards

Kiến thức cần nắm:

  • Dashboards: real-time, auto-refresh, DQL-powered tiles, shareable (even external)
  • Notebooks: snapshots, point-in-time, historical comparison, KHÔNG auto-refresh
  • Dashboard editing: modify charts, titles, filters, queries
  • Dashboard reports: subscribe email reports (weekly/monthly)

Docs tham khảo:

  • Dashboards
  • Notebooks

Module 4: Business Analytics & DEM

Kiến thức cần nắm:

  • DEM = RUM + Synthetics + Session Replay
  • RUM: Auto Injection (OneAgent inject JS), Apdex (0-3s-15s), User Actions, User Sessions
  • Agentless RUM: manual JS injection, same data output
  • Synthetics: Browser, Clickpath, HTTP monitors — không cần OneAgent
  • Session Replay: RECONSTRUCT (không phải video recording), masked by default
  • Business Events: extract business values từ logs/spans
  • Conversion Goals, Session completion rules (35 min idle, close window, 8h, 200 actions)

Docs tham khảo:

  • Digital Experience Monitoring
  • Define Applications for RUM
  • Synthetic Monitoring
  • Business Analytics

Module 5: Data, Reporting & Analysis

Kiến thức cần nắm:

  • DQL (Dynatrace Query Language): fetch | filter | sort | limit — query Grail
  • DQL dùng trong Dashboards + Notebooks + Logs/Traces Apps
  • Không cần admin rights cho DQL
  • Data Explorer: visual chart builder, convert sang DQL
  • Logs App & Traces App: dedicated apps cho raw data exploration
  • Dashboard Reports: email subscription
  • Dashboards API: programmatic dashboard management
  • User Analytics: bounce rate, conversion, session segmentation

Docs tham khảo:

  • Dynatrace Query Language
  • How to Use DQL Queries
  • Dashboard Reports
  • Dashboards API
  • User Behavior Analysis
  • Session Segmentation
  • Metrics on Grail

Module 6: DQL Deep Dive

Kiến thức cần nắm:

  • DQL syntax: pipe-based (|), giống Unix
  • fetch = lấy data (logs, metrics, spans, bizevents)
  • filter = lọc data
  • summarize = aggregate
  • sort, limit, fields = refine
  • DQL query Grail trực tiếp — không schema required (khác SQL)
  • Autocomplete + templates có sẵn

Hands-on: Learn DQL Beginners Exercise

Module 7: Security

Kiến thức cần nắm:

  • Runtime Vulnerability Analytics: phát hiện CVEs trong libraries đang chạy
  • Runtime Application Protection: chặn attacks real-time
  • DSS (Dynatrace Security Score): Snyk + Davis AI topology
  • Code-Level Vulnerabilities: lỗi trong code custom
  • Third-Party Vulnerabilities: lỗi trong open-source libraries
  • Davis Security Advisor: recommend fixes ưu tiên
  • Security Investigator: investigate threats dùng logs/metrics/traces trong Grail

Docs tham khảo:

  • Application Security
  • Third-Party Vulnerabilities
  • Code-Level Vulnerabilities
  • Davis Security Score
  • Security Investigator
  • Vulnerabilities App

Module 8: Automation

Kiến thức cần nắm:

  • AutomationEngine: AI-driven workflow automation
  • Workflows: trigger-based automation (problem → action)
  • No-code / low-code workflow builder
  • Use cases: auto-remediation, auto-ticketing, notifications, data ingestion

Docs tham khảo:

  • AutomationEngine
  • Introduction to Workflows
  • Workflows Quick Start

Module 9: Ingestion

Kiến thức cần nắm:

  • Log ingestion: OneAgent auto-discover + Logs Ingestion API (cho serverless/no-agent)
  • Data stored trong Grail
  • Cloud Integrations: AWS/Azure/GCP monitoring không cần OneAgent
  • VMware Monitor Hub: vCenter metrics + logs

Docs tham khảo:

  • Log Ingestion
  • Cloud Integrations
  • VMware vSphere Monitoring

Module 10: Other

Kiến thức cần nắm:

  • Smartscape topology: auto-discovered, real-time
  • Log Management & Analytics: filter, parse, analyze
  • Dynatrace Hub: marketplace cho apps, extensions, technologies

Docs tham khảo:

  • Smartscape
  • Log Content Analysis
  • Dynatrace Hub
