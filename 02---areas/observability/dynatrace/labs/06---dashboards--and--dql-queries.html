Lab 06 — Dashboards & DQL Queries

⏱️ Thời gian: ~45 phút
📋 Prerequisites: Lab 05 hoàn thành
🔗 Source: Dynatrace/easytrade

🎯 Mục Tiêu

Sau lab này, bạn sẽ:

  • Sử dụng Data Explorer để visualize metrics
  • Viết DQL queries cho metrics, entities, và business data
  • Tạo custom Dashboard cho EasyTrade
  • Thêm các loại tiles khác nhau (chart, table, markdown, SLO)
  • So sánh: DQL vs Datadog query language

Cách học lab này

Trình tự tốt nhất là câu hỏi trước, query sau, dashboard cuối cùng

  • Data Explorer giúp bạn học metric model của Dynatrace; DQL giúp bạn đặt câu hỏi sâu hơn; dashboard chỉ là nơi đóng gói những gì đáng xem lặp lại.
  • Nếu một chart trống hoặc khó hiểu, thường nguyên nhân nằm ở scope, split dimension, entity filter, hoặc time range hơn là platform không có dữ liệu.
  • Khi viết DQL, đừng chỉ chăm chăm nhớ cú pháp. Điều quan trọng hơn là biết mình đang truy vấn loại dữ liệu nào, field nào có sẵn, và kết quả query đó sẽ hỗ trợ một quyết định vận hành cụ thể ra sao.

1. Data Explorer — Visual Query Builder

1.1. Mở Data Explorer

  1. Vào Observe and explore → Explore data (hoặc Data Explorer)

1.2. Tạo chart đầu tiên

  1. Click Select metric → tìm builtin:service.response.time
  2. Split by: dt.entity.service (tách theo service)
  3. Time range: Last 2 hours
  4. Click Run query

🔍 Quan sát: Chart hiển thị response time cho mỗi EasyTrade service.

1.3. Các metric hữu ích

MetricMô tảUse case
builtin:service.response.timeService response timePerformance overview
builtin:service.errors.total.rateService error rate (%)Error monitoring
builtin:service.requestCount.totalRequest throughputTraffic monitoring
builtin:host.cpu.usageHost CPU %Infrastructure health
builtin:host.mem.usageHost memory %Capacity planning
builtin:containers.cpu.usagePercentContainer CPUPer-container health

💡 Metric naming convention: builtin:<entity>.<metric>.<aggregation>

  • builtin = metrics tự động bởi OneAgent
  • service/host/containers = entity type
  • response.time / errors.total = metric name
  • .rate / .count = aggregation type

1.4. Chart types

Thử đổi chart type trong Data Explorer:

TypeBest for
Line chartTrends over time (response time)
Bar chartComparisons (throughput per service)
Single valueCurrent state (current error rate)
TableDetailed breakdown
HeatmapDistribution (latency percentiles)
Pie chartProportions (traffic share per service)

💡 Power of unified DQL:

DQL query MỌI data type bằng cùng syntax:

  • fetch logs → log data
  • fetch dt.entity.service → topology data
  • timeseries → metric data
  • fetch events → problems/events data

Datadog dùng separate query languages cho mỗi loại data (metrics query, log search, trace search). DQL = 1 ngôn ngữ cho tất cả.

🔗 Fundamentals: Ch.03 — Query Languages. Concept query language (PromQL, LogQL, SQL) → DQL là unified alternative.

4. Dashboard Features

4.1. Time frame control

  • Dashboard-level time frame (top bar)
  • Individual tile time override (nếu cần)

4.2. Auto-refresh

  • Settings → Auto-refresh interval (30s, 1m, 5m)
  • Hữu ích khi để dashboard trên monitor

4.3. Variables (filtering)

  1. Dashboard settings → Variables
  2. Add variable:
    • Name: service
    • Type: Entity selector
    • Entity type: Service
  3. Apply variable lên tiles → filter by selected service

4.4. Share & Export

  • Share: Copy dashboard URL
  • Export: Download dashboard JSON
  • Import: Upload dashboard JSON (hữu ích khi rotate trial accounts!)

⚠️ Troubleshooting

No data in tiles

  • Kiểm tra time range — có thể quá ngắn / quá dài
  • EasyTrade có đang chạy? docker compose ps
  • Metric name đúng? Thử search trong Data Explorer trước

DQL query error

  • Check syntax và inline field suggestions trong editor
  • Thử query đơn giản trước (fetch logs | limit 5)
  • Xem Dynatrace DQL documentation cho syntax updates
