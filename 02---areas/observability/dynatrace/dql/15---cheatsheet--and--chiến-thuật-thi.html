6. Chiến thuật làm bài thi (practical)

6.1 Trước khi vào exam

2 tuần trước:

  • Hoàn thành 40 bài ở 13 - Bài tập thực hành DQL
  • Đăng ký Dynatrace Playground và làm quen UI
  • Làm Learn DQL app (Beginner’s Exercise + JSON Audit Logs)

1 tuần trước:

  • Làm 3 đề ở 14 - Đề thi mẫu & Mock Exam
  • Thuộc 10 snippet ở mục 5 file này
  • Ôn lại 5 use case đầu ở 10 - Use Cases thực tế

1 ngày trước:

  • Xem lại cheatsheet (mục 2) file này
  • Luyện tạo Dashboard + Notebook tile nhanh (dưới 2 phút/tile)
  • Nghỉ ngơi đầy đủ

6.2 Trong khi làm bài

Quy tắc 3 giây đầu:

  1. Đọc đề → xác định source data (logs/spans/bizevents/metrics)
  2. Xác định timeframe (mặc định 2h, hỏi 1 giờ → now()-1h)
  3. Xác định output expected (bảng? số? biểu đồ?)

Viết query theo thứ tự:

    A["1. fetch source"] --> B["2. filter"]
    B --> C["3. fieldsAdd"]
    C --> D["4. summarize"]
    D --> E["5. sort + limit"]
    E --> F["6. fields"]

Test từng bước bằng cách bỏ bớt dòng cuối và chạy thử — nhanh phát hiện lỗi.

6.3 Checklist trước khi “Submit” một task

  • Timeframe đúng với đề yêu cầu (không dùng mặc định khi đề nói “last 1h”)
  • Filter đúng điều kiện (đặc biệt case-sensitive: "ERROR" ≠ "error")
  • Aggregation (count, avg, …) đúng loại
  • Group by đúng field
  • Sort direction (asc/desc) đúng
  • Limit đúng số
  • Visualization đúng loại khi được yêu cầu (Line/Bar/Table/Single value)
  • Tên tile/section rõ ràng nếu exam yêu cầu
  • Query chạy ra data (không empty, không error)

7. Lỗi hay gặp & Fix nhanh

LỗiNguyên nhânFix
'ERROR' isn't allowed hereDùng in [...] với string literalsDùng hàm in(): in(field, {"ERROR", "WARN"}) hoặc dùng or
No data foundTimeframe quá ngắnTăng from:now()-7d
No data foundFilter sai caseDùng ~ hoặc matchesValue()
Field not foundTên field saiDùng autocomplete (Ctrl+Space)
Cannot compare ... to nullSo sánh với nullDùng isNull() / isNotNull()
Kết quả 0 hoặc integer lẻInteger divisionDùng toDouble()
Duration quá lớnĐơn vị nanosecondstoLong(duration) / 1000000
Metric trả nullDùng fetch thay vì timeseriesĐổi sang timeseries avg(metric)
Hiển thị entity ID dàiChưa dùng entityName()Thêm `
Chart không vẽOutput không phải timeseriesDùng makeTimeseries hoặc timeseries
Group by không hoạt độngQuên by:{} trong summarizeThêm by:{field}

8. Sơ đồ quyết định — Chọn command nào?

flowchart TD
    START{"Muốn làm gì?"}
    
    START -->|"Lấy data"| DS{"Loại data?"}
    DS -->|Logs| FL["fetch logs"]
    DS -->|Traces| FS["fetch spans"]
    DS -->|Business| FB["fetch bizevents"]
    DS -->|Events| FE["fetch events"]
    DS -->|Metrics| TM["timeseries avg(dt.xxx)"]
    DS -->|Entity| FDE["fetch dt.entity.host"]

    START -->|"Tổng hợp"| AGG{"Kiểu output?"}
    AGG -->|"1 số"| SC["summarize count()"]
    AGG -->|"Nhóm"| SG["summarize ..., by:{field}"]
    AGG -->|"Biểu đồ time"| MT["makeTimeseries"]

    START -->|"Lọc"| FLT{"Biết chính xác?"}
    FLT -->|"Có"| FEQ["filter field == val"]
    FLT -->|"Không"| FWC["filter field ~ pat*"]
    FLT -->|"Nhiều value"| FIN["in(field, {a, b})"]
    FLT -->|"Full-text"| FSR["search text"]

    START -->|"Chuyển đổi"| CVT{"Loại?"}
    CVT -->|"Ép kiểu"| TL["toLong / toDouble"]
    CVT -->|"Field mới"| FA["fieldsAdd new = expr"]
    CVT -->|"Parse"| PA["parse content, pattern"]
    CVT -->|"ID → tên"| EN["entityName(id)"]
