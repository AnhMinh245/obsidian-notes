DQL — Parse & Trích xuất dữ liệu từ Text

Mức độ: Trung cấp
Mục tiêu: Biết cách trích xuất dữ liệu có cấu trúc từ log message dạng text thô, JSON, key-value pairs bằng lệnh parse và Dynatrace Pattern Language (DPL).

1. Tại sao cần parse?

Log thường là text thô như thế này:

2026-04-01 10:23:45 ERROR [web-01] user=alice action=login status=failed ip=192.168.1.100

Bạn muốn trích xuất: timestamp, level, user, action, status, ip thành các field riêng để filter, aggregate được. Đây là nhiệm vụ của parse.

2. Cú pháp lệnh parse

  • field: field chứa text cần parse (thường là content)
  • pattern: mẫu parse viết bằng Dynatrace Pattern Language (DPL)

3. DPL — Dynatrace Pattern Language

DPL là ngôn ngữ mô tả cấu trúc của text để trích xuất dữ liệu. Học DPL = biết cách “mô tả” log line.

3.1 Matchers — Mô tả đoạn text

MatcherMô tảVí dụ match
WORDMột từ (chữ cái, số, _)hello, user123
NSPACEText không có khoảng trắngweb-server-01
DATABất kỳ text nàoBất kỳ
LD”Lazy data” — bất kỳ, dừng khi gặp pattern tiếpLinh hoạt
INTSố nguyên42, -5
LONGSố nguyên dài9876543210
DOUBLESố thực3.14, -0.5

IPV4IPv410.0.0.1

6. Parse Key-Value Pairs (KVP)

Dùng KVP khi log có dạng key=value key=value ...:

Log mẫu:

user=alice action=login status=success duration=234ms

Giải thích KVP pattern:

KVP{                        ← bắt đầu key-value pairs
    WORD:key                ← key là một WORD
    '='                     ← separator là dấu =
    NSPACE:value            ← value là text không có space
    (' ' | EOS)             ← tiếp theo là space hoặc End Of String
}:attrs                     ← kết quả lưu vào field "attrs" (là một Record)

11. Tóm tắt

Tình huốngPattern/Cách làm
Parse JSONparse field, "JSON:result"
Parse key=valueparse field, "KVP{WORD:key '=' NSPACE:value ...}:result"
Parse IP addressIPADDR:field_name
Parse số nguyênLONG:field_name hoặc INT:field_name
Bỏ qua đoạn textLD (dừng trước pattern tiếp) hoặc DATA (lấy hết)
