DQL — Kiểu dữ liệu & Toán tử

Mức độ: Trung cấp
Mục tiêu: Hiểu các kiểu dữ liệu trong DQL, cách chuyển đổi giữa chúng, và sử dụng đúng các toán tử.

1. Tại sao cần hiểu kiểu dữ liệu?

DQL là strongly typed — mỗi field có kiểu dữ liệu cụ thể. Nếu truyền sai kiểu vào hàm, query sẽ báo lỗi. Hiểu kiểu dữ liệu giúp bạn:

  • Tránh lỗi type mismatch
  • Biết khi nào cần chuyển đổi (cast)
  • Tính toán đúng với timestamp, duration, number

2. Kiểu dữ liệu nguyên thủy (Primitive Types)

2.1 Boolean

Chỉ có 2 giá trị: true và false.

Tri-state boolean với null:
DQL dùng 3 trạng thái: true, false, null. Khi so sánh với null, kết quả là null (không phải false).
