Mock Practical Pack — 16 Tasks (sát đề thi)

Cách dùng

  • Bấm giờ 60 phút cho 16 tasks (≈ 3.5 phút/task).
  • Làm trên demo.live.dynatrace.com hoặc playground tenant.
  • Sau mỗi task, đối chiếu với Expected output + Screenshot checklist.
  • Tự chấm: pass nếu đặt đúng tên + screenshot đủ evidence.

Naming convention quan trọng

  • Đặt tên dashboard / notebook / tile / monitor đúng nguyên văn đề.
  • Screenshot lưu dạng .png, đặt tên file rõ ràng (vd task01-dashboard.png).
  • Một task có thể cần 2-3 screenshot (config + result).

Phân bố 16 tasks theo Tier

TierTasksThời gian khuyến nghị
Tier 1 (Dashboard, Notebook, Data Explorer, Synthetic)1, 2, 3, 4, 5, 625 phút
Tier 2 (RUM, Traces, Logs, Vulnerabilities)7, 8, 9, 10, 11, 1222 phút
Tier 3 (Hosts, Workflow, BizEvents)13, 14, 15, 1613 phút

Task 01 — Dashboard gen3: CPU per host (Tier 1)

Yêu cầu:

  • Tạo dashboard gen3 tên Mock-CPU-Dashboard.
  • Thêm 1 DQL tile tên Avg CPU per host - 2h.
  • Hiển thị average CPU usage của tất cả hosts trong 2 giờ qua, split by host.
  • Visualization: line chart.

Expected output:

  • Dashboard list xuất hiện Mock-CPU-Dashboard.
  • Tile có tên Avg CPU per host - 2h.
  • Line chart hiển thị nhiều đường (1 line / host).

DQL gợi ý:

Screenshot checklist:

  • Toàn dashboard view với tile.
  • Tab Data của tile hiển thị query.
  • Tab Visual đặt line chart.

📚 Xem chi tiết: 01 - Practical - Dashboard gen3 DQL tile

Task 06 — Synthetic HTTP monitor (Tier 1)

Task 12 — Vulnerability DSS Critical (Tier 2 — SPOTLIGHT 9.3)

Yêu cầu:

  • Mở Vulnerabilities app.
  • Filter theo Dynatrace Security Score ≥ 9.0 (Critical).
  • Chọn 1 vulnerability có DSS gần 9.3 (hoặc bất kỳ Critical).
  • Đọc Affected entities + Public internet exposure.

Expected output:

  • Filter applied → list vulnerabilities Critical.
  • Side panel Overview hiển thị DSS calculation breakdown.

Screenshot checklist:

  • Filter bar với “Dynatrace Security Score >= 9.0”.
  • Side panel Overview của vulnerability đã chọn.
  • Tab Affected entities.

📚 Xem chi tiết: 08 - Practical - Vulnerabilities DSS Security
