2. Auto-Instrumentation — So sánh chi tiết

Dynatrace OneAgent

graph TD
    OA["OneAgent cài trên host"] --> PS["1. Process Scan<br/>(quét /proc)"]
    PS --> TD["2. Technology Detection<br/>(Java, .NET, Python, Go...)"]
    TD --> CI["3. Code Injection<br/>(bytecode injection vào runtime)"]
    CI --> SD["4. Service Detection<br/>(từ incoming requests)"]
    SD --> DM["5. Dependency Mapping<br/>(build Smartscape tự động)"]
    DM --> BL["6. Baseline Learning<br/>(Davis AI học pattern ~1 tuần)"]
  • Không cần sửa source code — OneAgent inject vào bytecode tại runtime
  • Hỗ trợ auto-instrumentation: Java, .NET, Node.js, PHP, Python (bytecode injection)
  • Auto-inject x-dynatrace + W3C traceparent headers cho distributed tracing
  • PurePath = end-to-end trace từ browser → backend → DB

Go Exception — Exam Trap!

Go compiles to native binary (không có VM/runtime) → không có bytecode injection.
→ Go applications cần dùng OneAgent SDK để instrument thủ công.
Đây là ngoại lệ duy nhất trong các ngôn ngữ Dynatrace hỗ trợ auto-instrumentation.

OneAgent Deployment Modes cho Kubernetes

ModeImplementationPrivilegesUse case
classicFullStackDaemonSet trên mỗi nodeCao (root/privileged)Default, full visibility
cloudNativeFullStackWebhook + CSI DriverThấp hơn (no race conditions)Cloud-native, security-first
applicationMonitoringApp-only injectionThấp nhấtChỉ cần APM, không cần infra
  • classicFullStack: cài OneAgent trực tiếp trên node (DaemonSet) → full host + process + application monitoring
  • cloudNativeFullStack: dùng Webhook để inject vào pods + CSI Driver mount volume → không cần privileged containers, tránh race conditions khi pod start
  • applicationMonitoring: chỉ inject vào application pods → không monitor host/infrastructure

Exam tip

cloudNativeFullStack = recommended cho production K8s vì lower privileges + no race conditions.

Datadog APM

graph TD
    Dev["Developer thêm ddtrace vào app"] --> AI["Auto-instrument frameworks<br/>(Flask, Django, Express...)"]
    AI --> CS["Custom spans<br/>(business logic)"]
    CS --> Agent["Traces → Agent (TCP 8126)"]
    Agent --> DD["→ Datadog Backend (HTTPS 443)"]
  • Cần thêm library vào app — ddtrace (Python), dd-trace-go (Go), v.v.
  • Auto-instrument = library hook vào framework (không inject bytecode)
  • Propagate trace context qua X-Datadog-Trace-Id + X-Datadog-Parent-Id headers
  • Cũng hỗ trợ W3C traceparent (configurable)

Single Step Instrumentation — SSI (Datadog)

  • Zero-code APM setup — không cần sửa Dockerfile hoặc thêm ddtrace thủ công
  • SSI auto-inject ddtrace SDK vào application tại runtime
  • Hỗ trợ: Java, Python, Node.js, .NET, Ruby
  • Chỉ cần annotate pods (K8s) hoặc enable trong Agent config

SSI vs USM (Universal Service Monitoring):

  • SSI: inject tracing library → full APM traces (distributed tracing, custom spans)
  • USM: eBPF-based, capture ở kernel level → service map + golden signals ONLY (không có code-level traces)
  • USM = backup khi không thể instrument (legacy apps, polyglot)

So sánh trực tiếp

BướcDynatraceDatadog
Cài đặtCài OneAgent lên host/containerCài Agent + thêm ddtrace library vào app
ConfigGần zero (auto-detect tất cả)Config datadog.yaml + conf.d/*.d/conf.yaml
Code changes❌ Không cầnTối thiểu (import ddtrace, hoặc chạy ddtrace-run python app.py)
Injection methodBytecode injection (runtime)Library patching (monkey-patching frameworks)
DepthCode-level visibility (method-level profiling)Framework-level (HTTP handlers, DB calls)
Custom business dataRequest attributes, Business Events APICustom spans, custom tags
Trace contextx-dynatrace + W3C auto-injectedX-Datadog-* headers, W3C optional

Ghi nhớ cho exam

Dynatrace: “Cài OneAgent, xong” — zero-config là USP.
Datadog: “Cài Agent + thêm ddtrace library + bật từng feature” — nhiều bước hơn nhưng linh hoạt hơn.

Datadog Agent Components — Default States

ComponentDefault StatePortGhi chú
Collector✅ Enabled—Chạy checks mỗi 15s, đọc /proc/*
Forwarder✅ EnabledHTTPS 443Gửi data về Datadog backend
DogStatsD✅ EnabledUDP 8125Custom metrics daemon
APM/Trace Agent✅ EnabledTCP 8126Enabled by default từ Agent v7

EXAM TRAP — Log Agent OFF by default!

Datadog Agent KHÔNG thu thập logs by default.
Phải explicitly set logs_enabled: true trong datadog.yaml.
Đây là câu hỏi trap phổ biến trong Datadog exam!

Integration metricsExtensions (Dynatrace Hub)Agent-based checks (mỗi 15s, conf.d/*.d/conf.yaml)

DogStatsD — Khái niệm KHÔNG có trong Dynatrace

DogStatsD là daemon nhận custom metrics qua UDP port 8125 từ app:

# Wire format: metric_name:value|type|@sample_rate|#tags
order.placed:1|c|#env:prod,service:order
order.processing_time:0.35|h|#env:prod
  • Aggregate mỗi 10 giây rồi flush to Forwarder
  • Dùng UDP → app không bao giờ bị block bởi monitoring
  • Sample rate (@0.1) = gửi 10% packets, DogStatsD nhân lên ×10

Dynatrace equivalent: Metric Ingestion API hoặc OneAgent SDK — nhưng KHÔNG có statsd daemon riêng.

4. Thu thập Logs

Khía cạnhDynatraceDatadog
Default✅ OneAgent auto-collect❌ TẮT by default — phải bật logs_enabled: true
DiscoveryAuto-discover log files mỗi 60 giâyConfig trong conf.d/*.d/conf.yaml
Container logsAuto-collect stdout/stderrConfig Docker/K8s log collection
API pushPOST /api/v2/logs/ingestPOST /api/v2/logs
ExtensionsTechnology-specific extensionsIntegration log configs

Datadog Logs — DISABLED by default!

Không giống Dynatrace (OneAgent auto-collect logs), Datadog Agent tắt log collection by default.
Phải thêm logs_enabled: true trong datadog.yaml VÀ config từng source trong conf.d/.
Đây là điểm khác biệt quan trọng nhất giữa 2 platform về log collection.

5. Thu thập RUM (Real User Monitoring)

Khía cạnhDynatraceDatadog
JS injectionAuto-inject bởi OneAgent trên web serverManual: thêm <script> tag (DD RUM SDK)
AlternativeManual snippet hoặc AgentlessCDN hoặc npm package
Session trackingUser Sessions (30min timeout, 6h max)RUM Sessions
CorrelationAuto-link RUM → PurePath (backend traces)Cần Unified Service Tagging (env/service/version)
Key metricApdex scoreCore Web Vitals + custom

Khác biệt quan trọng

Dynatrace auto-inject JS cho RUM nếu OneAgent đã cài trên web server. Datadog yêu cầu developer thêm RUM SDK thủ công.
