AI và Anomaly Detection

2. Dynatrace Intelligence — 3 loại AI

Rebranding 2025+: “Davis AI” đã được rebrand thành Dynatrace Intelligence — umbrella term cho toàn bộ AI capabilities. Tên “Davis” vẫn được dùng trong một số docs cũ.

2.1. Causal AI (trả lời “TẠI SAO?”)

graph TD
    A["DETECT<br/>Phát hiện anomaly events riêng lẻ"] --> B["TRAVERSE<br/>Đi dọc Smartscape dependency graph"]
    B --> C["CORRELATE<br/>Check cùng time window + cùng dependency tree"]
    C --> D["IDENTIFY<br/>Xác định root cause + impact chain"]
    D --> E["CONSOLIDATE<br/>Gộp nhiều anomalies → 1 Problem"]

Đặc điểm cốt lõi:

  • Deterministic — cùng input = luôn cho cùng output
  • Không cần ML training data — dùng logic trên topology graph
  • Smartscape là nền tảng — hiểu “Service A gọi Service B, Service B dùng DB C”
  • Khi DB C chết → Davis biết: root cause = DB C, impact = Service B → Service A

Ví dụ consolidation:

20 events riêng lẻ:
- Service A latency spike
- Service B error rate increase  
- Service C timeout
- DB connection pool exhausted
- Host disk I/O spike
...

Davis consolidate → 1 Problem:
  Root cause: Disk full trên DB host
  Impact: DB → Service C → Service B → Service A

2.2. Predictive AI (trả lời “SẼ xảy ra gì?”)

  • Dynamic baselines: học patterns theo giờ/ngày/tuần
  • Baseline ổn định sau ~1 tuần
  • Hiểu context: 300ms lúc 2AM = ANOMALY, 300ms lúc 9AM = NORMAL
  • Dự đoán: disk sẽ đầy trong X ngày, memory leak sẽ OOM trong Y giờ

2.3. Generative AI — Dynatrace Assist (trả lời “GIẢI THÍCH và GỢI Ý”)

  • Formerly “Davis CoPilot” — rebranded to Dynatrace Assist (2025+)
  • Agentic multi-step reasoning — không chỉ trả lời, mà tự execute workflow
  • NL→DQL: chuyển câu hỏi tiếng Anh thành DQL query tự động
  • Auto-generate dashboards từ mô tả
  • Giải thích Problems bằng ngôn ngữ tự nhiên
  • Gợi ý remediation steps

DT 2026 — Agentic OS Vision

Dynatrace đang phát triển Agentic OS — nền tảng cho domain-specific AI agents:

  • SRE Agent: auto-detect, auto-prevent, auto-remediate incidents
  • Security Agent: threat detection + auto-response
  • DevOps Agent: auto-optimize deployments, CI/CD feedback loop
  • Tầm nhìn: từ “AI giúp bạn” → “AI tự hành động thay bạn” (auto-prevent → auto-remediate → auto-optimize)

3. Datadog — Watchdog + Bits AI

3.1. Watchdog — ML Anomaly Detection Engine (Foundation)

graph TD
    M["Metrics data<br/>(continuous)"] --> WD["Watchdog ML Engine"]
    T["Traces data"] --> WD
    L["Logs data"] --> WD
    WD --> WI["Watchdog Insights<br/>(contextual cards)"]
    WI --> WA["Watchdog Alerts<br/>(proactive notifications)"]
    WI --> WS["Watchdog Stories<br/>(grouped anomalies)"]

Watchdog = ML-based anomaly detection engine:

  • Auto-runs, zero-config — chạy nền trên toàn bộ telemetry data
  • Foundation layer — Bits AI USES data surfaced by Watchdog nhưng là layer riêng biệt
  • Tự phát hiện: latency spikes, error rate increases, throughput anomalies

Watchdog Coverage:

  • APM: error rate anomalies, latency anomalies, hit rate anomalies
  • Infrastructure: host metrics, container metrics
  • Logs: log anomaly detection (pattern changes, volume spikes)

Watchdog Features chi tiết:

  • Watchdog Insights: contextual cards hiện trong APM, Log Explorer, Dashboards, Notebooks khi phát hiện anomaly liên quan đến context đang xem
  • Watchdog Alerts: proactive notifications — không cần tạo monitor, tự gửi alert khi phát hiện anomaly
  • Watchdog Stories: nhóm related anomalies thành narrative, timeline view
  • Faulty Deployment Detection: tự phát hiện deploy gây regression (error rate tăng, latency tăng sau deploy event)
  • 3rd-Party Outage Detection: phát hiện downstream dependency outage (AWS, GCP, Stripe…) ảnh hưởng đến services
  • Forecasting: dự đoán resource exhaustion trends
  • Outlier Detection: phát hiện 1 instance behaving differently vs peers

3.2. Bits AI — Agentic AI Teammates (DASH 2025-2026)

Bits AI ≠ Watchdog

Watchdog = ML anomaly detection engine (foundation, auto-runs).
Bits AI = suite of agentic AI teammates — sử dụng data từ Watchdog + toàn bộ platform để tự hành động, không chỉ phát hiện.

Bits AI = suite of agentic AI teammates, introduced tại DASH 2025, expanded significantly tại DASH 2026:

AgentChức năngStatus
Bits AI SREAutonomous incident investigation, root cause analysis, tự triageGA Dec 2025
Bits CodeGenerate code fixes từ telemetry data, tạo PR trực tiếpDASH 2026
Bits DetectionAuto-create/maintain detection coverage, dynamic baselinesDASH 2026 Preview
Bits ReleaseAutonomous release validation, PR→production trackingDASH 2026
Bits Testing AgentAuto-generate synthetic test suites từ production trafficDASH 2026
Bits Security AnalystSecurity threat detection + investigation workflowsDASH 2026

Platform capabilities:

  • Agent Builder: custom AI agent workflows với 2000+ Action Catalog — kết nối DD data với bất kỳ tool nào
  • Agent Console: monitor hiệu suất tất cả AI agents — giám sát agent tự chạy
  • AI Guard: bảo vệ chống prompt injection, agent poisoning, data exfiltration
  • Bits Memories: learn từ historical operational context — agents “nhớ” cách team đã xử lý incidents trước đó

3.3. Datadog Anomaly Monitor (user-configured)

Khác với Watchdog (tự động), Anomaly Monitor do user tạo:

AlgorithmMô tảUse case
BasicRolling mean ± N standard deviationsSimple patterns
AgileAdapts fast to level shiftsMetrics that change quickly
RobustIgnores outliers in baseline learningNoisy metrics
# Ví dụ: Alert khi request rate bất thường
avg:trace.flask.request.hits{env:prod} 
  → Anomaly Monitor (Agile, 2 deviations, weekly seasonality)

Root Cause Analysis

FeatureDynatrace IntelligenceDatadog (Watchdog + Bits AI)
Auto RCA✅ Causal AI trên Smartscape graph⚠️ Watchdog Insights gợi ý + Bits AI SRE autonomous investigation (GA 2025)

Khác biệt triết lý AI

Dynatrace Intelligence: “Tôi TÌM root cause cho bạn” — deterministic, topology-based (Smartscape), output = Problem card.
Watchdog + Bits AI: “Tôi PHÁT HIỆN anomalies (Watchdog) VÀ TỰ HÀNH ĐỘNG (Bits AI)” — ML detection + agentic automation, developer-focused, action-oriented.

    AE["Anomaly Events<br/>(7 categories)"] --> DC["Davis Consolidation"]

    P --> AP["Alerting Profile<br/>(filter by severity/tags/MZ)"]

7 Event Categories (theo severity):

PriorityCategory
1 (highest)Monitoring Unavailable
2Availability
3Error
4Slowdown
5Resource

Datadog Events + Monitors

graph LR
    M["Monitor evaluates metric"] --> S["State change<br/>(OK → Warn → Alert → No Data)"]
    S --> N["Notification<br/>(PagerDuty, Slack, Email...)"]
    E["Events<br/>(deployments, integrations)"] --> D["Dashboard overlay"]

Monitor States: OK → Warn → Alert → No Data

No Data ≠ metric = 0

“No Data” trong Datadog = không nhận được data points — khác hoàn toàn với metric có giá trị 0!

6. Predictive Capabilities

FeatureDynatraceDatadog
Resource exhaustionDavis Predictive AI (disk, memory, CPU trends)Forecast Monitor (time series extrapolation)
Anomaly patternsDavis learns weekly/dailyAnomaly Monitor (3 algorithms)
Peer comparison❌ Không explicitOutlier Monitor (1/10 servers behaving differently)
Composite logicAlerting Profile filtersComposite Monitor (AND/OR logic across monitors)

Forecast Monitor (Datadog-specific)

Disk usage trending +0.71%/day 
→ Forecast Monitor predicts: 100% full in 70 days
→ Alert NOW to schedule cleanup

Dynatrace: Davis Predictive AI làm tương tự nhưng tự động (không cần tạo monitor riêng).

Outlier Monitor (Datadog-specific)

10 web servers serving same traffic:
- 9 servers: latency ~200ms
- 1 server: latency ~2000ms ← OUTLIER
→ Alert: "web-server-07 is an outlier"

Dynatrace: không có monitor type tương đương. Davis AI phát hiện qua baseline anomaly per entity.
