Dashboards và Visualization

2. Dashboard Types — So sánh

Dynatrace Dashboards

  • Classic Dashboards: Tile-based, drag-and-drop
  • Dashboard (new): DQL-powered, flexible layouts
  • Notebooks: Interactive analysis — mix DQL queries, text, charts (giống Jupyter)
  • Data Explorer: Ad-hoc metric/log exploration

Datadog — Timeboard vs Screenboard

FeatureTimeboardScreenboard
Time sync✅ Tất cả widgets cùng time range❌ Mỗi widget có time range riêng
LayoutGrid-based, automaticFree-form, drag anywhere
Use caseTroubleshooting (correlation)NOC display (status board)
Template Variables✅✅

Timeboard/Screenboard = LEGACY

Phân biệt Timeboard/Screenboard là khái niệm legacy. Datadog hiện dùng unified grid-based Dashboard. Các API cũ (timeboard/screenboard) đã deprecated — dùng datadog_dashboard cho Terraform.
Tuy nhiên exam cũ có thể vẫn hỏi: troubleshooting → Timeboard concept (synchronized time), NOC display → Screenboard concept (free layout).

Exam trap

Câu hỏi “debugging/troubleshooting” → Timeboard (synchronized time)
Câu hỏi “NOC/status display” → Screenboard (free layout, big numbers)

So sánh

DynatraceDatadog
Classic Dashboard ≈Screenboard (free layout)
Notebook (interactive) ≈Timeboard (synchronized time) + Notebook
Data Explorer ≈Metric Explorer
Dynatrace Apps ≈OOTB Integration Dashboards

Event Overlay (Datadog — trên Timeseries widgets)

Đặt vertical markers trên timeseries chart cho events (deployments, alerts, scaling):

Timeseries chart showing CPU usage
   │         ↓ Deploy v2.3        ↓ Alert fired
   │    ────/\───────────/\──────/\────
   │   /        \       /    \  /      \
   └──────────────────────────────────────→ time

Dynatrace: Problem events hiện trên timelines nhưng không có manual event overlay tương tự.

4. Template Variables (Datadog)

Dropdown filters ảnh hưởng tất cả widgets trên dashboard:

Dashboard: Production Overview
┌─────────────────────────────────────┐
│ env: [prod ▾]  service: [all ▾]    │
│ region: [us-east ▾]                │
├─────────────────────────────────────┤
│ [CPU chart]  [Memory chart]        │
│ [Error rate] [Latency p99]         │
└─────────────────────────────────────┘
  • Tạo từ tag keys: $env, $service, $region
  • Thay đổi 1 dropdown → tất cả widgets auto-filter
  • Rất quan trọng — giúp 1 dashboard phục vụ nhiều team/env

Dynatrace: Management Zone filter ở top dashboard + Variable support trong new Dashboards.
