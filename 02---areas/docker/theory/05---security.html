1. Non-Root User (Quan trọng nhất)

Mặc định container chạy với root (UID 0) — rủi ro bảo mật cao.

Vấn đề khi chạy root

Giải pháp: USER instruction

UID/GID Best Practice

Dùng UID trong range 1000-65535. Tránh dùng UID < 1000 (system users).
Trên Fedora/RHEL, UID từ 1000 trở lên là safe.

3. Linux Capabilities

Linux kernel chia quyền root thành ~40 capabilities nhỏ hơn.

Drop tất cả, chỉ add những gì cần

Tip

Apps chạy trên port > 1024 (3000, 8080, etc.) không cần bất kỳ capability nào khi chạy với non-root user. Dùng --cap-drop ALL.

6. Minimal Base Images

Distroless (Google)

Ưu điểm distroless:

  • ✅ Không có shell → không thể exec vào container
  • ✅ Không có package manager → không cài thêm được
  • ✅ Attack surface cực kỳ nhỏ
  • ✅ ~2-5MB cho static binaries
