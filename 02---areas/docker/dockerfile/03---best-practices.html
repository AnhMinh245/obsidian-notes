Production-Ready Checklist

🔒 Security

  • Dùng non-root user (USER instruction)
  • Không hardcode secrets (passwords, API keys)
  • Pin base image version cụ thể (không dùng latest)
  • Dùng multi-stage để loại bỏ build tools
  • Scan vulnerabilities với Trivy / Docker Scout
  • .dockerignore ngăn copy .env, .git, secrets

📦 Size Optimization

  • Dùng base image nhỏ (alpine, slim, distroless)
  • Multi-stage builds
  • Xóa cache trong cùng RUN layer
  • .dockerignore loại trừ node_modules, __pycache__, .git

⚡ Build Speed

  • Sắp xếp layers: ít thay đổi → hay thay đổi
  • Copy dependency files trước source code
  • Dùng BuildKit cache mounts (--mount=type=cache)
  • Enable BuildKit: export DOCKER_BUILDKIT=1

🔧 Maintainability

  • LABEL với maintainer, version, description
  • Pin dependency versions (requirements.txt, package-lock.json)
  • Dùng HEALTHCHECK
  • Comment những phần không rõ ràng
  • Exec form cho CMD/ENTRYPOINT

🏃 Runtime

  • HEALTHCHECK endpoint
  • Exec form CMD ["node", "app.js"] (không phải shell form)
  • EXPOSE đúng port
  • Config qua ENV (không hardcode)
