Image Naming Convention

[registry/][namespace/]repository[:tag][@digest]

Ví dụ:
nginx                                 → docker.io/library/nginx:latest
node:18-alpine                        → docker.io/library/node:18-alpine
myuser/myapp:1.0.0                    → docker.io/myuser/myapp:1.0.0
ghcr.io/myorg/myapp:latest            → GitHub Container Registry
registry.example.com/team/myapp:v2   → Private registry

Pin Images by Digest (Immutable)

Tại sao dùng digest?

Tags có thể thay đổi nội dung (mutable). Digest là immutable — cùng digest = cùng content chính xác.
Dùng trong production Dockerfiles để đảm bảo reproducibility.
