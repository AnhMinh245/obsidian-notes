virsh là gì?

virsh (virtualization shell) là CLI client của libvirt — công cụ chính để quản lý VM, network, storage trên KVM. Mọi thao tác có thể thực hiện qua virsh hoặc libvirt API.

VM State Diagram

Trước khi đi vào commands, hiểu vòng đời của một VM:

                 virsh define
  (XML file) ────────────► DEFINED (shut off)
                                   │
                          virsh start
                                   │
                                   ▼
                              RUNNING ◄───────── virsh resume
                             ┏━━┓ ┏━━┓                   ▲
                 virsh       ┃  ┃ ┃  ┃  virsh             │
                 shutdown    ┃  ┃ ┃  ┃  suspend            │
                 │           ┗━━┛ ┗━━┛            PAUSED ─┘
                 ▼                                          
            SHUT OFF ◄────── virsh destroy (force)
                 │
        virsh undefine
                 │
                 ▼
             UNDEFINED (gone)

7. Snapshots

Snapshot best practices

  • Dùng --atomic để đảm bảo consistency
  • Freeze filesystem trước nếu có guest agent: virsh domfsfreeze myvm
  • Snapshot chỉ tạm thời — commit hoặc delete sau khi xong
  • Snapshot chain dài → performance giảm
