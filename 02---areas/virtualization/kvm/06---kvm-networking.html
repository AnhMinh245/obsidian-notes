2. NAT Network (Default)

2.1. Cách hoạt động

VM (192.168.122.100)
    │
    │ vNIC (virtio)
    ↓
virbr0 (192.168.122.1/24) ── Linux bridge
    │
    │ iptables MASQUERADE (NAT)
    ↓
Host NIC (enp1s0, 10.0.0.5) → Physical Network → Internet
  • libvirt tạo bridge virbr0 + chạy dnsmasq (DHCP + DNS)
  • VM nhận IP từ DHCP range (192.168.122.2 - 254)
  • Outbound traffic: NAT qua host IP
  • Inbound traffic: cần port forwarding

Fedora 39+: nftables thay iptables

Trên Fedora mới, libvirt dùng nftables backend thay vì iptables cho NAT rules. iptables commands vẫn hoạt động qua compatibility layer nhưng nft list ruleset | head -50 cho kết quả chính xác hơn.

4. Isolated Network

4.1. Cách hoạt động

VM1 (10.20.30.11) ↔→ VM2 (10.20.30.12) ↔→ VM3 (10.20.30.13)
         │                   │                   │
         └───────── virbr-isolated ──────────────┘
                  (bridge, NO forwarding)
                  VMs nói chuyện với nhau
                  Host có IP trên bridge (10.20.30.1)
                  → Host↔VM: OK qua bridge IP
                  → VM→Internet: KHÔNG

9.2. Áp dụng nwfilter cho VM

clean-traffic filter kết hợp:

  • no-mac-spoofing: chặn VM đổi MAC
  • no-ip-spoofing: chặn VM dùng IP khác
