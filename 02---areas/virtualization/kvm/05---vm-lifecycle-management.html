4. Snapshot Management

4.1. Internal vs External Snapshots

Internal Snapshot (trong file QCOW2):
  disk.qcow2 chứa cả base data + snapshot delta
  ✅ Đơn giản, 1 file
  ❌ Chậm hơn, chỉ dùng với QCOW2

External Snapshot (file riêng):
  base.qcow2 (frozen) ← overlay.qcow2 (active writes)
  ✅ Nhanh hơn, không ảnh hưởng base
  ❌ Nhiều file phải quản lý

5.4. Migration Phases

Phase 1: Setup
  Host A thông báo Host B: "VM sẽ migrate sang"
  Host B tạo QEMU process chờ
      │
Phase 2: Transfer Memory (iterative)
  Round 1: copy toàn bộ RAM (ví dụ: 8GB)
  Round 2: copy dirty pages (pages thay đổi trong round 1)
  Round 3: copy dirty pages (ít hơn)
  ...
  Convergence: dirty rate < transfer rate
      │
Phase 3: Stop-and-Copy (downtime)
  VM pause → copy remaining dirty pages → resume trên Host B
  Downtime: thường 10-100ms
      │
Phase 4: Cleanup
  Host B: VM running
  Host A: VM stopped, undefine (nếu --undefinesource)
