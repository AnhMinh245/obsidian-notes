┌─────────────────────────────────────────────────────────┐
│  VM (Guest OS)                                          │
│  ├── /dev/vda (virtio-blk)    ← fast, simple            │
│  └── /dev/sda (virtio-scsi)   ← flexible, multi-LUN     │
└─────────────────┬───────────────────────────────────────┘
                  │ I/O request
                  ↓
┌─────────────────────────────────────────────────────────┐
│  QEMU (Userspace)                                       │
│  ├── Block layer: format driver (qcow2, raw, vmdk)      │
│  ├── Cache mode: none / writeback / writethrough         │
│  └── AIO backend: native / threads / io_uring            │
└─────────────────┬───────────────────────────────────────┘
                  │

┌─────────────────────────────────────────────────────────┐
│  Host OS (Linux)                                        │
│  ├── Filesystem: ext4, XFS, ZFS, Btrfs                  │

│  └── Hardware: NVMe, SAS, SATA, HBA                     │

Khi nào virtio-blk vs virtio-scsi?

  • virtio-blk: ít disks (< 28), đơn giản, performance cao nhất
  • virtio-scsi: nhiều disks, cần SCSI commands (UNMAP/TRIM), hot-plug disk
