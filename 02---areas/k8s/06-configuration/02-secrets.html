📦 Secret Là Gì?

Giải Thích Bằng Ví Dụ Thực Tế

🏢 VÍ DỤ CÔNG TY:

Bạn đang deploy web app, cần kết nối database:
├── Database host: db.example.com       → ConfigMap (✅ ai xem cũng OK)
├── Database port: 5432                  → ConfigMap (✅ không nhạy cảm)
├── Database password: P@ssw0rd!         → SECRET (🔐 chỉ app mới biết!)
├── API key: sk-abc123xyz                → SECRET (🔐 bí mật!)
└── TLS certificate: cert.pem            → SECRET (🔐 private key!)

Rule: KHÔNG BAO GIỜ đặt passwords/tokens trong ConfigMaps!

Secret = K8s object lưu sensitive data dạng base64-encoded

Quan trọng: Base64 chỉ là encoding (ai cũng decode được), KHÔNG phải encryption (mã hóa)!

🆚 Secret vs ConfigMap

FeatureConfigMapSecret
PurposeNon-sensitive configSensitive data
EncodingPlain textBase64-encoded
ExampleDatabase host, log levelPasswords, API tokens
At restPlain textCan be encrypted
Size limit1 MiB1 MiB
tmpfs mountNoYes (memory, không ghi disk)
RBACThường openNên restrict
ImmutableSupportedSupported

⚠️ Secret volumes được mount dưới dạng tmpfs (in-memory filesystem) — data không bao giờ ghi xuống disk trên Node.

🎮 Consume Secrets

Pattern 1: Environment Variables (Đơn giản)

⚠️ Nhược điểm env vars:

  • Env vars có thể bị log (application logs, crash dumps)
  • Không hot-reload khi Secret thay đổi
  • Child processes inherit env vars

Pattern 2: Volume Mount (An toàn hơn)

Ưu điểm volume mount:

  • ✅ Mounted dưới tmpfs (in-memory, không ghi disk)
  • ✅ Hot-reload khi Secret thay đổi (~60s kubelet sync)
  • ✅ Không bị leak qua env var dumps
  • ✅ File permissions kiểm soát chặt

Tại Sao Cần?

Giống Immutable ConfigMaps:
├── Ngăn chặn accidental changes
├── Performance: kubelet không cần watch changes
├── Scale: Giảm API Server load (nhiều Pods watch = nhiều load)
└── Security: Đảm bảo credentials không bị sửa đổi

├── Compliance requirements (PCI-DSS, SOC2): rotate mỗi 90 ngày
├── Employee leave → revoke access
└── Best practice: Giảm blast radius khi bị leak

🎯 Key Takeaways

  1. Secrets = Sensitive Data (passwords, tokens, keys)

    • Base64-encoded ≠ encrypted
    • Enable encryption at rest!

  2. vs ConfigMap

    • Secrets: Sensitive → RBAC + encryption
    • ConfigMap: Non-sensitive → open access OK
    • Never put passwords in ConfigMaps!

  3. Consume

    • Volume mount (an toàn hơn — tmpfs, hot-reload, file permissions)
    • Env vars (đơn giản nhưng less secure — có thể bị log)
    • Luôn readOnly: true cho volume mounts

  4. Immutable Secrets

    • immutable: true cho production
    • Versioned strategy khi cần thay đổi

  5. Production Security Stack

    • ✅ Encryption at rest
    • ✅ RBAC: Least privilege
    • ✅ External secrets (Vault / Cloud provider)
    • ✅ Sealed Secrets cho GitOps
    • ✅ Regular rotation
    • ✅ Audit access

  6. Advanced: CSI Secrets Store Driver

    • Mount trực tiếp từ Vault, không qua K8s Secret
    • Auto-rotation
    • Không lưu trong etcd
