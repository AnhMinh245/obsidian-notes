🎯 Mục Tiêu

  • Gán labels taxonomy cho resources
  • Query bằng equality-based và set-based selectors
  • Annotations cho metadata (Prometheus, CI/CD)
  • Thêm/xóa labels on-the-fly

Bước 1: Labels Taxonomy

✅ Checkpoint

Bước 2: Selectors

💡 Labels là nền tảng K8s:

  • Service → selector để tìm Pods (Lab 14)
  • Deployment → selector để quản lý Pods (Lab 09)
  • NetworkPolicy → labels để define rules (Lab 27)
  • HPA → target Deployment qua labels (Lab 24)

✅ Checkpoint

  • Filter bằng equality-based và set-based selectors

Bước 3: Thêm/Xóa Labels On-the-fly

✅ Checkpoint

  • Thêm/overwrite/xóa labels on-the-fly

Bước 4: Annotations

💡 Labels vs Annotations:

LabelsAnnotations
Select/Query✅ -l key=value❌
Size63 chars maxLớn hơn nhiều
Dùng bởiK8s selectorsExternal tools (Prometheus, Ingress)
Ví dụapp: podinfoprometheus.io/scrape: "true"

✅ Checkpoint

  • Annotations cho Prometheus scraping
  • Hiểu Labels (select) vs Annotations (metadata)

🧹 Cleanup

🎤 Interview Questions

  1. Labels vs Annotations? → Labels: identify/select, queryable, K8s dùng. Annotations: metadata cho tools, không query được.
  2. Set-based selector in hoạt động? → tier in (frontend,backend) = match tier=frontend HOẶC tier=backend.
  3. Recommended labels? → app.kubernetes.io/name, app.kubernetes.io/version, app.kubernetes.io/component, app.kubernetes.io/managed-by.
