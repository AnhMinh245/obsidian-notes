EX294 — Exam Objectives chính thức

Tổng hợp từ trang chính thức Red Hat, đối chiếu ngày 25/09/2026. Đây là bản tham chiếu chuẩn cho kế hoạch thi RHCE.

⚠️ Thay đổi tên chứng chỉ — tháng 5/2026

Red Hat đã tái cấu trúc toàn bộ chương trình chứng chỉ từ 11/05/2026 thành 5 track chuyên biệt (Enterprise Linux · Ansible · OpenShift · Cloud-native applications · AI), mỗi track có 5 bậc.

✅ Kết luận quan trọng: bạn vẫn lấy được danh hiệu bậc Engineer

Có một chỗ dễ hiểu nhầm: tên kỳ thi nghe như bậc “Advanced System Administrator” (thấp hơn Engineer), nhưng danh hiệu thì không.
RHCSA (EX200) + EX294 = Red Hat Certified Engineer in Ansible — bậc 3 trong track Ansible.
Bạn đã có RHCSA 300/300 (hiệu lực tới 2028), nên chỉ cần pass EX294 là lên thẳng bậc Engineer. Luận điểm “RHCE hiếm và có giá trị” của bạn vẫn đứng vững nguyên vẹn.

💡 Ghi gì lên CV năm 2027

Ghi “Red Hat Certified Engineer in Ansible (EX294)”. Nếu muốn qua được bộ lọc từ khoá của HR thì thêm dạng quen thuộc trong ngoặc: Red Hat Certified Engineer in Ansible (RHCE, EX294). Người giữ chứng chỉ RHCE cũ được grandfather, không bị mất hiệu lực.

🔴 RHEL 9 hay RHEL 10 — phải hỏi trước khi dựng lab

Tình hình tính tới 25/09/2026:

  • Khoá chính thức của Red Hat hiện là AU294, dựa trên RHEL 10 · ansible-core 2.16 · AAP 2.6. Khoá cũ RH294 dựa trên RHEL 9 · AAP 2.2.
  • Kỳ thi EX294 bản RHEL 9 vẫn là bản đang mở đăng ký; bản RHEL 10 đã được công bố và một số đơn vị đào tạo đã rao lịch học theo RHEL 10.

Vì sao quan trọng với bạn: plan hiện tại dựng lab 4 VM Rocky Linux 9. Nếu công ty đăng ký nhầm bản RHEL 10 thì lab lệch phiên bản.

Hành động: khi nộp đề xuất, hỏi rõ “kỳ thi EX294 phiên bản nào — RHEL 9 hay RHEL 10”. Chưa có câu trả lời thì cứ dựng lab Rocky 9 vì đó là bản đang mở đăng ký.

Mức độ ảnh hưởng nếu lệch: nhỏ. Danh sách objectives của hai bản giống nhau; khác biệt nằm ở phiên bản ansible-core, bộ ansible-dev-tools, và vài mặc định của hệ điều hành. Kỹ năng học trên RHEL 9 chuyển sang RHEL 10 gần như trọn vẹn — nhưng biết trước vẫn hơn.

⚠️ Cần xác nhận khi công ty đăng ký

Thời lượng và điểm đạt ở bảng trên không có trên trang objectives công khai. Hỏi bộ phận đào tạo xác nhận lại cùng lúc với câu hỏi phiên bản đề.

Điều kiện & khuyến nghị của Red Hat

  • Điều kiện tiên quyết cho danh hiệu: phải có RHCSA (EX200) ✅ bạn đã có
  • Kinh nghiệm khuyến nghị: hoàn thành RH124 + RH134 (hoặc RH199), và AU294 — hoặc kinh nghiệm tương đương
  • Red Hat yêu cầu rõ: xem lại cả objectives của EX200 trước khi thi EX294 ⚠️ (xem phần lỗ hổng bên dưới)

🎯 Exam Objectives đầy đủ

Nhóm và nội dung theo trang chính thức. Thuật ngữ giữ nguyên tiếng Anh vì đề thi dùng đúng những từ này.

1. Understand core components of Ansible

  • Inventories
  • Modules
  • Variables
  • Facts
  • Loops
  • Conditional tasks
  • Plays
  • Handling task failure
  • Playbooks
  • Configuration files
  • Roles
  • Use provided documentation to look up specific information about Ansible modules and commands

2. Install and configure an Ansible control node

  • Create and modify ansible.cfg
  • Modify ansible-navigator.yml
  • Create a static host inventory file
  • Create and use static inventories to define groups of hosts

3. Configure Ansible managed nodes

  • Create and distribute SSH keys to managed nodes
  • Configure privilege escalation on managed nodes
  • Deploy files to managed nodes
  • Validate a working configuration using ad hoc Ansible commands

4. Run playbooks with automation content navigator

  • Know how to run playbooks with both ansible-navigator and ansible-playbook
  • Use ansible-navigator to find new modules in available Ansible Content Collections
  • Use ansible-navigator to create inventories and configure the Ansible environment

5. Use source control and development tools

  • Clone a Git repository
  • Add files to a Git repository
  • Create playbooks and push them to a Git repository using Visual Studio Code
  • Configure ansible-navigator and run playbooks using an Ansible development container

6. Create Ansible plays and playbooks

  • Know how to work with commonly used Ansible modules
  • Use variables to retrieve the results of running a command
  • Use conditionals to control play execution
  • Configure error handling
  • Create playbooks to configure systems to a specified state

7. Use roles and Ansible Content Collections

  • Create and work with roles
  • Install roles and use them in playbooks
  • Install Content Collections and use them in playbooks

8. Automate standard RHCSA tasks using Ansible modules

Tự động hoá bằng module Ansible cho các nhóm:

  • Software packages and repositories
  • Services
  • Firewall rules
  • File systems
  • Storage devices
  • File content
  • Archiving
  • Task scheduling
  • Security
  • Users and groups

💡 Bảng ánh xạ: tác vụ RHCSA đã biết → module Ansible

Đây là nhóm objective chiếm nhiều điểm nhất. Bạn đã làm thủ công thành thạo mọi tác vụ dưới đây khi thi RHCSA 300/300 — việc duy nhất cần học là tên module. Học theo bảng này, đừng học lại khái niệm Linux.

⚠️ Hai bẫy kinh điển của nhóm này

  • firewalld: có permanent: true mà quên immediate: true → rule chỉ có hiệu lực sau reload. Đề chấm trạng thái thật của máy nên phải có cả hai.
  • sefcontext: chỉ ghi vào policy, không đổi label của file đang tồn tại. Phải chạy thêm restorecon mới có hiệu lực.

9. Manage content

  • Create and use templates to create customized configuration files
  • Use Ansible Vault in playbooks to protect sensitive data

10. RHCSA-level competencies (vẫn nằm trong phạm vi thi)

  • Understand and use essential tools
  • Operate running systems
  • Configure local storage
  • Create and configure file systems
  • Deploy, configure and maintain systems
  • Manage users and groups
  • Manage security
  • Be able to analyze simple shell scripts

🔴 Hai lỗ hổng cần vá

⚠️ Lỗ hổng 1 — VS Code và Ansible development container

Objective 5 ghi rõ hai thứ mà plan hiện tại chưa có: tạo playbook bằng VS Code rồi push lên Git, và chạy playbook trong development container. Plan mới chỉ có phần Git thuần.
Cách vá: thêm 1 buổi vào RW4 — cài extension Ansible cho VS Code, chạy thử ansible-navigator trong dev container (ansible-dev-tools), rồi làm trọn vòng viết → commit → push từ trong VS Code.

⚠️ Lỗ hổng 2 — nền RHCSA và shell script

Red Hat nói thẳng trong phần điều kiện: phải xem lại objectives của EX200. Kỳ thi EX294 giả định bạn vẫn làm được mọi thứ ở mức RHCSA, và objective còn ghi riêng “analyze simple shell scripts”.
Bạn thi RHCSA 300/300 cuối 2025 nên nền rất chắc, nhưng đã gần một năm.
Cách vá: thêm 1 buổi ôn nhanh trong RW7 — đọc lướt objectives EX200, tự làm lại 3-4 tác vụ hay quên (LVM thủ công, systemd unit, quyền ACL, SELinux context), và đọc hiểu 2-3 shell script mẫu có vòng lặp và if.

🧭 Định hướng ôn — thứ tự ưu tiên theo trọng số thực tế

Red Hat không công bố % điểm cho từng nhóm objective. Nhưng vì đề chấm bằng trạng thái thật của máy sau khi chạy playbook, trọng số thực tế nghiêng hẳn về nhóm nào tạo ra nhiều thay đổi hệ thống nhất:

  1. Objective 8 — tự động hoá tác vụ RHCSA 🔴 nặng nhất. Mười nhóm tác vụ, mỗi nhóm đều có thể thành một task chấm điểm riêng. Đây là nơi bạn có lợi thế lớn nhất nhờ nền RHCSA: chỉ cần học ánh xạ tác vụ đã biết → module Ansible.
  2. Objective 6 + 9 — playbook, template, Vault 🔴 xương sống của mọi task khác.
  3. Objective 7 — roles 🟠 gần như chắc chắn có ít nhất một task yêu cầu tạo role từ đầu.
  4. Objective 2 + 3 + 4 — cấu hình môi trường 🟠 làm đầu giờ thi, làm sai thì mọi task sau đều hỏng.
  5. Objective 5 — Git, VS Code, dev container 🟡 ít điểm hơn nhưng rất dễ mất trắng nếu không tập vì thao tác lạ tay.
  6. Objective 1 + 10 — nền tảng 🟡 không thi trực tiếp nhưng thấm vào mọi task.

💡 Nguyên tắc ôn xuyên suốt, rút ra từ chính cách chấm

Đề chấm kết quả trên máy, không chấm code đẹp. Hệ quả:

  • Playbook chạy được nhưng xấu vẫn full điểm. Playbook đẹp mà không chạy được thì 0 điểm.
  • Luôn chạy lại playbook lần 2 để chắc chắn idempotent và không lỗi.
  • Cấu hình phải sống sót qua reboot (/etc/fstab, enabled: true, SELinux persistent, firewalld permanent). Nếu task nói “persistent” mà bạn quên, máy chấm sẽ thấy trạng thái sai.
  • ansible-doc là bạn đồng hành duy nhất trong phòng thi. Tập tra module bằng nó tới mức phản xạ, đừng dựa vào note.

🚫 Các khoá "practice test" trắc nghiệm — bỏ qua hết

Đã xem 2 khoá:

  • Imran Afzal — “RHCE EX294 Practice Exams”: 5 bài × 40 câu, 90 phút/bài. Chỉ 40 lượt đánh giá.
  • BalaSagar — “EX294: RedHat Advanced System Administrator in Ansible” (8/2026, ~239k₫): 6 bài × 250 câu = 1500 câu. Bản đồ syllabus thực ra tốt nhất trong các khoá practice (có Navigator, Git & VS Code, Collections, Storage/Identity/Security) và tác giả dùng đúng tên chứng chỉ mới. Nhưng: khoá mới toanh, 1 học viên / 1 đánh giá, và tác giả chuyên xuất bản practice test cho AWS/GCP/AI chứ không phải Red Hat — không có cách nào kiểm chứng 1500 câu đó đúng hay sai.

Vấn đề gốc chung: EX294 là 4 tiếng gõ terminal, chấm bằng trạng thái thật của máy. Trắc nghiệm kiểm tra bạn nhớ gì, đề thi kiểm tra bạn làm được gì — đây là chỗ nhiều người nhầm rồi trượt.

Chi phí thật không phải tiền mà là thời gian: 1500 câu × ~1 phút ≈ 25 tiếng ≈ gần 3 tuần quỹ học. Số giờ đó bỏ vào lab thì giá trị hơn nhiều.

💡 Cách tự kiểm tra bất kỳ khoá RHCE nào trong 2 phút

Mở mục lục khoá, Ctrl+F tìm 4 từ: navigator · collection · template · git.
Thiếu cả 4 → tài liệu thời RHEL 8, không đủ cho đề hiện tại. Đây là cách phát hiện nhanh khoá bị lỗi thời, vì ngày “cập nhật gần nhất” không phản ánh việc nội dung có bám objectives hay không.

1. Phương án trả phí — chỉ dùng nếu thấy thiếu sau khi học xong khoá trên

Sander van Vugt — “Red Hat Certified Engineer (RHCE) EX294 Complete Video Course, 2nd Edition” (~9 tiếng, RHEL 9)

  • Bám sát objectives, mỗi bài kết thúc bằng lab walkthrough — đúng thứ cần cho đề thực hành.
  • Độ dài hợp lý: 9 tiếng video gọn trong 2 tuần đầu, để dành 8 tuần còn lại cho tay chân trên lab.
  • Có trên O’Reilly, Pearson IT Certification, hoặc mua trực tiếp từ sandervanvugt.com.
  • Nếu đề là RHEL 10: tác giả đã có bản riêng “RHCE (RHEL10) EX294”.

⚠️ Về cuốn Cert Guide của cùng tác giả

Bạn đã có thư mục Cert Guide - Sander van Vugt trong vault. Lưu ý cuốn Cert Guide bản in là cho RHCE 8 (xuất bản 2020) — phần Ansible phần lớn vẫn đúng, nhưng thiếu ansible-navigator, Content Collections và execution environment vốn là objectives của bản RHEL 9. Dùng sách làm tài liệu tra cứu phụ, lấy khoá video RHEL 9 làm chuẩn.

2. Bộ đề thực hành — quan trọng nhất với đề 100% hands-on 🥇

Ghada Atef — “RHCE EX294 Practice Exams” (có bản cho RHEL 9 và bản riêng cho RHEL 10)

  • 6 bài lab full-length kèm lời giải và bước verify — đúng thứ mà hầu hết giáo trình thiếu.
  • Dùng cho tuần mock exam (RW7 / RW8) thay vì tự nghĩ đề.
  • ⚠️ Sách tự xuất bản, tôi chưa kiểm chứng được chất lượng trực tiếp — đọc thử phần xem trước trên Amazon trước khi mua.

3. Lab của chính bạn — miễn phí và không thay thế được 🥇

4 VM Rocky Linux 9 + snapshot. Không có tài liệu nào thay được việc gõ thật. Đây là khoản đầu tư quan trọng nhất và nó miễn phí.

💡 Đáng hỏi công ty — có thể miễn phí với bạn

Nhiều doanh nghiệp đối tác của Red Hat đã có sẵn ghế Red Hat Learning Subscription hoặc quota khoá học chưa dùng hết. Hỏi cùng lúc với câu hỏi về voucher thi. Nếu có RHLS thì đây là lựa chọn tốt nhất vì lab được dựng sẵn đúng phiên bản, không phải tự lo.

5. Vá lỗ hổng nền RHCSA

Asghar Ghori — “RHCSA Red Hat Enterprise Linux 9: Training and Exam Preparation Guide (EX200), 3rd Edition” — 99 bài tập, 74 challenge lab. Có thể bạn đã có từ hồi ôn RHCSA. Chỉ dùng để rà nhanh phần quên, không đọc lại từ đầu.

6. Tuỳ chọn thêm — chỉ khi dư thời gian

  • Jeff Geerling — “Ansible for DevOps”: rất hay để hiểu Ansible thực chiến, nhưng không theo cấu trúc đề thi. Để sau khi thi xong.
  • Tài liệu Ansible chính thức (docs.ansible.com): tra cứu ngoài giờ. Nhưng nhớ trong phòng thi chỉ có ansible-doc — nên đừng tạo thói quen phụ thuộc vào docs online.

🚫 Tránh xa các trang "dumps"

Kết quả tìm kiếm về EX294 đầy rẫy site bán “exam dumps”. Ba lý do bỏ qua: (1) đề thi là thực hành nên câu hỏi trắc nghiệm ăn cắp vô dụng, (2) vi phạm thoả thuận thi của Red Hat và có thể bị huỷ chứng chỉ, (3) tiền đó mua bộ đề lab thật thì hữu ích hơn nhiều.
