🚀 Hướng Dẫn Triển Khai Obsidian

Tài liệu này mô tả toàn bộ cấu hình Obsidian hiện tại và cách tái tạo lại trên một máy mới. Bao gồm: cài đặt app, clone vault, cấu hình plugins, theme, fonts, và Git sync.

🗂️ Cấu Trúc Vault (PARA Method)

~/Obsidian/
├── 00 - Inbox/          # Ghi chú mới, chưa xử lý
├── 01 - Projects/       # Dự án đang thực hiện
├── 02 - Areas/          # Lĩnh vực dài hạn (học tập, công việc...)
├── 03 - Resources/      # Tài liệu tham khảo (đây là thư mục này)
├── Attachments/         # File đính kèm, ảnh
├── 07 - Literature/     # Literature notes: Books/, Articles/
├── 06 - Journal/        # Nhật ký: Daily/ (YYYY-MM-DD), Weekly/, Monthly/
├── Dynatrace/           # Tài liệu chứng chỉ Dynatrace
├── Excalidraw/          # Bản vẽ và sơ đồ
├── Templates/           # Mẫu ghi chú
│   ├── Daily Note.md
│   ├── Project.md
│   └── Tech Research.md
└── .obsidian/           # Config (tracked by Git)

📦 Bước 1: Cài Đặt Dependencies

1.1 Fonts Cần Thiết

Vault dùng Inter và JetBrains Mono. Cần cài trước khi mở Obsidian.

NOTE

Nếu fonts không có trong repo Fedora, tải file .ttf và đặt vào ~/.local/share/fonts/, sau đó chạy fc-cache -fv.

🎨 Bước 6: Cài Đặt Theme AnuPpuccin

Theme này không được lưu vào Git (chỉ config appearance.json được lưu). Cần cài thủ công:

  1. Mở Obsidian → Settings → Appearance → Manage themes
  2. Tìm kiếm “AnuPpuccin”
  3. Click Install and use

🔌 Bước 7: Cài Đặt Community Plugins

Vì thư mục plugins/ đã được clone từ Git, các plugins đã sẵn sàng. Tuy nhiên cần kích hoạt chúng trong Obsidian:

  1. Settings → Community plugins → Turn on community plugins
  2. Tất cả plugins bên dưới sẽ xuất hiện và đã được kích hoạt.

⚙️ Bước 8: Cấu Hình Obsidian Git

Plugin này cần cấu hình lại sau khi clone vì data.json bị gitignore:

  1. Settings → Community plugins → Obsidian Git → Options
  2. Thiết lập:
    • Auto backup interval: 15 phút
    • Auto push interval: 15 phút
    • Auto pull interval: 15 phút
    • Pull method: Merge
    • Commit message: vault backup: {{date}}

📋 Cấu Hình App Hiện Tại

app.json (Settings → Files & Links)

Core Plugins Đang Bật

  • File Explorer, Global Search, Quick Switcher, Graph View
  • Backlinks, Outgoing Links, Tag Pane, Page Preview
  • Daily Notes, Templates, Note Composer, Command Palette
  • Bookmarks, Outline, Word Count, File Recovery
  • Properties, Canvas, Slash Commands, Markdown Importer
  • Slides, Sync (built-in), Bases

🎯 Kiểm Tra Sau Khi Cài

Sau khi hoàn thành tất cả bước, kiểm tra:

  • Obsidian mở được và hiển thị vault đúng
  • Theme AnuPpuccin được áp dụng (màu tím violet)
  • CSS snippet modern-ui.css đang bật (Settings → Appearance → CSS snippets)
  • Font Inter và JetBrains Mono hiển thị đúng
  • Daily Notes tạo đúng format YYYY-MM-DD vào folder 06 - Journal/Daily/
  • Plugin Obsidian Git hoạt động (status bar hiển thị branch main)
  • Templater hoạt động khi tạo file mới từ Templates/
  • Graph View hiển thị các nodes có màu violet
