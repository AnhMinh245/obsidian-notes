Local AI Setup — Ollama + Lemonade cho Dualboot (Windows 11 + Fedora)

⚠️ TẠM DEFER (2026-04-20) — primary AI approach hiện tại là external agents (Cursor / Codex / Antigravity) mở trực tiếp folder vault. Xem External AI Agents - Cursor Codex Antigravity.

Doc này vẫn giữ nguyên để khôi phục nhanh khi cần (offline, privacy paranoid, benchmark). Ollama installed nhưng không auto-start; models qwen-fast, qwen2.5:7b-instruct, nomic-embed-text, gemma4:e4b giữ nguyên trên D:\AI\models\ollama\ (13.57 GB). Copilot plugin đã disable nhưng vẫn cài trong vault.

Quick recovery (khi cần bật lại):

  1. Move D:\AI\logs\Ollama.lnk.disabled → %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Ollama.lnk (hoặc double-click C:\Users\anhminh\AppData\Local\Programs\Ollama\ollama app.exe)
  2. Obsidian → Settings → Community plugins → enable Copilot (đã cấu hình qwen-fast sẵn)
  3. Test: curl http://localhost:11434/api/tags

Embedding nomic-embed-text vẫn được Smart Connections dùng — nếu Smart Connections báo lỗi → khởi động Ollama như bước 1.

Hướng dẫn cài & cấu hình local LLM stack cho máy Ryzen 7 8845H (Hawk Point, XDNA 1 NPU 16 TOPS) + 32GB LPDDR5X-7500 + Radeon 780M iGPU 4GB, dùng chung vault Obsidian ở cả Windows 11 và Fedora.

Đọc kèm: External AI Agents - Cursor Codex Antigravity (primary), AI Setup - Copilot and Smart Connections (Smart Connections section), Smart Second Brain Playbook.

⚠️ Pitfall phát hiện khi setup thực tế (2026-04-20, Ollama v0.21.0 + Gemma 4 ngày 3 tháng thứ 18)

1. Gemma 4 + Ollama 0.21 — HTTP API response rỗng

  • ollama pull gemma4:e4b thành công (9.6 GB, 8.0B params, Q4_K_M).
  • ollama run gemma4:e4b "Say hi." qua CLI → “Hi! 👋” bình thường.
  • POST /api/generate hoặc /api/chat → eval_count đếm 200 tokens, nhưng field response / message.content chỉ có 0-11 ký tự. Context IDs trong raw JSON cho thấy model sinh nhiều special tokens (236800, 236829…) là image/audio markers multimodal — detokenizer Ollama 0.21 skip hết.
  • Hệ quả: Obsidian Copilot plugin + Smart Connections không chạy được với gemma4:e4b cho đến khi Ollama release fix (track: https://github.com/ollama/ollama/issues).
  • Workaround hiện tại: dùng qwen2.5:7b-instruct làm default local chat. Giữ gemma4:e4b cho CLI test hoặc khi upgrade Ollama >0.21.

2. Vulkan iGPU AMD Radeon 780M — numerical corruption với Gemma 4

  • Bật OLLAMA_VULKAN=1 → Ollama detect được 780M với 17.7 GiB VRAM shared memory (lớn hơn kỳ vọng 4GB dedicated — hệ thống share từ RAM hệ thống).
  • Nhưng Vulkan backend alloc buffer >4GB thất bại: ErrorOutOfDeviceMemory (hard limit iGPU AMD). Ollama fallback split 42/43 layers lên GPU → output ? ? ? (numerical instability).
  • Hệ quả: hiện tại phải giữ OLLAMA_VULKAN=0 (CPU only). AVX-512 + AVX-512 VNNI trên 8845H đủ cho 7-10 tok/s, dùng được cho daily.
  • Khi nào re-enable: Ollama release Vulkan fix cho AMD iGPU + model buffer partitioning. Có thể thử lại với qwen2.5:7b (model nhỏ hơn, có thể alloc 1 buffer dưới 4GB).

3. PowerShell Set-Content -Encoding utf8 thêm BOM

  • Ollama Go JSON parser reject request có BOM → {"error":"invalid character 'A_' looking for beginning of value"}.
  • Fix: [System.IO.File]::WriteAllText(path, content, [System.Text.UTF8Encoding]::new($false)) để write UTF-8 không BOM.

4. Invoke-RestMethod PowerShell hiển thị sai UTF-8 emoji/tiếng Việt

  • Content model trả đúng (ví dụ “Hello! 👋”) nhưng console PowerShell render thành Hello! dY\<` (emoji bytes qua cp1252).
  • File saved with Out-File -Encoding utf8 đúng.
  • Không ảnh hưởng Obsidian Copilot plugin (JS runtime xử lý UTF-8 native).

1. Chiến lược storage chung cho dualboot

Vấn đề

  • Model files nặng (5–18 GB/model), không muốn download 2 lần cho 2 OS.
  • Embeddings cache phải đồng bộ giữa 2 OS (Obsidian vault đã dùng chung).
  • Config Copilot/Smart Connections trỏ cùng endpoint.

Giải pháp — share model cache qua partition NTFS

Ổ D:\ (NTFS, 500 GB) accessible từ cả Windows lẫn Fedora (Fedora auto-mount NTFS qua ntfs-3g). Ta dùng D:\AI\models\ làm central model store.

│   └── lemonade\           # Lemonade cache

4. Lemonade — thử NPU hybrid

Cảnh báo hardware: NPU XDNA 1 trên Ryzen 7 8845H (16 TOPS) không phải target chính của Lemonade hybrid mode (vốn tối ưu cho XDNA 2 trên Strix Point/Halo, 50+ TOPS). Trên 8845H, Lemonade chủ yếu fallback CPU+iGPU, NPU chỉ assist một phần prefill. Đừng kỳ vọng boost lớn — đây là optional, thử để so sánh.

4.1. Windows 11 — khuyến nghị chính

Lemonade trên Windows mature hơn nhiều vì AMD Ryzen AI Software chỉ chính thức support Windows cho NPU drivers.

Kiểm tra NPU driver:

Nếu NPU driver thiếu: download AMD Ryzen AI Software từ https://ryzenai.docs.amd.com → install drivers đi kèm.

4.2. Fedora — experimental only

AMD không release driver NPU XDNA chính thức cho Linux. Có project amdxdna upstream (kernel 6.10+) nhưng Fedora 40 cần manual build. Thực dụng:

  • Trên Fedora: skip Lemonade, dùng Ollama + iGPU Vulkan là đủ.
  • Nếu thực sự muốn thử: theo dõi https://github.com/amd/xdna-driver và https://github.com/lemonade-sdk/lemonade (Linux preview).

5. Cấu hình Copilot & Smart Connections trỏ về local

Bước thủ công qua UI Obsidian (không edit data.json trực tiếp)

⚠️ QUAN TRỌNG — num_ctx trap (2026-04-20): Qwen 2.5 / Llama 3.x / Gemma 4 có num_ctx default trong model metadata là 131072 (128k). Nếu Copilot chỉ add bằng model name thô thì Ollama sẽ alloc ~7 GB RAM KV cache và mất ~2 phút/request lần đầu load. Luôn tạo Modelfile variant với num_ctx=8192 cho CPU inference trên máy 32GB.

  • Embedding KHÔNG đổi (luôn là nomic-embed-text local để giữ consistency vault index).

9. Security & privacy

  • Local model = không rò dữ liệu. Phù hợp cho notes có tag: #private.
  • D:\AI\models\ không commit vào git (đã trong .gitignore vault root).
  • Không mở OLLAMA_HOST=0.0.0.0 khi máy trong wifi công cộng.
  • Nếu chạy Lemonade server, firewall block port 8000 cho mọi interface trừ 127.0.0.1.

10. Lộ trình upgrade (khi nào nâng cấp hardware)

Chỉ nâng cấp khi cả 2 điều sau xảy ra liên tục >1 tháng:

  1. Bạn thực sự dùng local LLM daily (>5 query/ngày, không phải thử nghiệm).
  2. Model hiện tại (gemma4:26b-moe) không đủ chất lượng ở task quan trọng.

Options theo chi phí (tham khảo, giá 2026-04):

Desktop Ryzen AI Max+ 395 (Strix Halo)~40trThay máy, 128GB unified + XDNA 2Gemma 4 31B FP16, Llama 70B Q4
Mac mini M4 Pro 64GB~45trAlt ecosystem, MLX stackGemma 4 31B, Llama 70B Q4 via MLX
