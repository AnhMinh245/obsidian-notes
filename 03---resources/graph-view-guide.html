Graph View Guide

Cấu hình Graph View cho vault này theo PARA+ để graph dễ đọc, có cluster rõ ràng, lộ được legacy folder cần migrate. File config: .obsidian/graph.json.

1. Color legend

Mở Graph View (Ctrl+G) → sidebar Groups đã unfold sẵn. Màu theo vai trò folder:

MàuFolder / queryVai trò
🔴 Đỏ05 - MOCsHub nodes — Map of Content, điểm tụ của domain
🟡 Vàng sáng00 - InboxAttention — fleeting chưa process (mục tiêu: < 10 notes)
🔵 Xanh dương01 - ProjectsActive projects — có deadline, outcome rõ
🟢 Xanh lá02 - AreasOngoing areas — trách nhiệm liên tục (domain chính)
🟠 Cam03 - ResourcesReference — tài liệu, note có thể tái dùng
⚫ Xám04 - ArchiveInactive — ít nổi bật
🟣 Tím06 - Journal + Daily NotesNhật ký, timeline
🟤 NâuProjects, Books, interviews (legacy)Chưa migrate sang PARA+ — cần dọn dần
⚪ Trắng (default)Note khác, không khớp group nàoFallback

→ Note màu nâu = tín hiệu visual: migrate vào 01 - Projects, 03 - Resources, hoặc 04 - Archive tuỳ status.

2. Filter (search bar)

Query hiện tại loại khỏi graph các folder kỹ thuật / không phải content:

-path:"Templates" -path:"copilot" -path:"Attachments" -path:"Excalidraw" -path:".obsidian"
  • Templates/ — template files gây nhiễu link network
  • copilot/ — chat history plugin (không phải kiến thức)
  • Attachments/ / Excalidraw/ — media, không có text connection
  • .obsidian/ — settings, plugins

Mở rộng filter khi cần

  • Chỉ xem 1 domain: thêm tag:#domain/observability vào search
  • Ẩn archive: thêm -path:"04 - Archive"
  • Chỉ evergreen: thêm ["status: evergreen"] (frontmatter search)
  • Show 1 MOC + neighbors: search file name của MOC, enable Neighbors = on + depth 2

Kết quả: MOC (đỏ) tự nhiên trở thành gravity center của mỗi cluster domain; Areas (xanh lá) gom cụm; Resources (cam) rải xung quanh các MOC liên quan; orphan lẻ tẻ nằm rìa.

6. Bảng mã màu (RGB integer)

Obsidian lưu màu trong graph.json dưới dạng số nguyên. Công thức: R*65536 + G*256 + B.

#F8E71C16312092🟡 Vàng sáng (Inbox)
#4A90E24886754🔵 Xanh dương (Projects)
#7ED3218311585🟢 Xanh lá (Areas)
#F5A62316098851🟠 Cam (Resources)
#9B9B9B10197915⚫ Xám (Archive)
#BD10E012390624🟣 Tím (Journal)

Chuyển hex → integer nhanh: [Convert]::ToInt32('4A90E2', 16) trong PowerShell.

7. Local graph (per-note view)

Command Palette → “Open local graph” (Ctrl+Alt+G): chỉ hiện note hiện tại + neighbors trong N hops.

Config local graph tách riêng, lưu trong .obsidian/graph.json dưới key khác khi lưu. Khuyến nghị:

  • Depth: 1 (chỉ láng giềng trực tiếp) cho weekly review
  • Depth: 2-3 cho synthesis sâu, tìm liên kết gián tiếp

8. Workflow dùng Graph View

Hàng ngày

  • Mở local graph khi ghi atomic note mới → thấy ngay note đã link đủ MOC chưa.

Hàng tuần (Weekly Review)

  • Mở global graph, filter path:"00 - Inbox" → thấy inbox còn bao nhiêu + đã có link nào.
  • Filter path:"01 - Projects" → check projects nào đang orphan (không link MOC / Area).

Hàng quý (Quarterly audit)

  • Brown node audit: zoom vào legacy clusters (Projects/, Books/, interviews/) → quyết định migrate sang PARA+ hoặc archive.
  • Orphan cleanup: filter showOrphans on, bulk rename hoặc add backlink vào MOC.
  • MOC health: mỗi MOC đỏ nên có >5 link vào nó — nếu <3 có thể là MOC yếu, cần expand hoặc merge với MOC khác.

Dọn legacy folders (kế hoạch đề xuất)

LegacyMove targetCách xử lý
Projects/ (21 notes)Active → 01 - Projects/; done/dead → 04 - Archive/2024-Projects/Mở từng note, check status frontmatter
Books/ (3 notes)✅ Đã migrate sang 07 - Literature/Books/ (2026-09-12)Frontmatter type: book đã bổ sung đủ 3 note
interviews/ (12 notes)03 - Resources/Interviews/ hoặc 02 - Areas/Career/Interviews/Nhóm theo company
Daily Notes/ (7 notes)✅ Đã migrate sang 06 - Journal/Daily/YYYY-MM-DD.md (2026-09-12)Folder Daily Notes/ đã xoá; .obsidian/daily-notes.json khớp sẵn
copilot/ (17 chats)Giữ nguyên, đã exclude filter graphPlugin sẽ xoá nếu user dùng Command Palette Copilot: Clear chat history

Sau khi dọn xong, mở graph.json → xoá group “Legacy” (không còn node nâu nào).
