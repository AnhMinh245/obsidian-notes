AI Rules — Áp Dụng Tự Động Cho Mọi AI Tool

Tài liệu này giải thích kiến trúc “single source of truth + adapters” đang được dùng trong vault, và cách cắm rule vào các AI tool không tự đọc file (vd Obsidian Copilot plugin).

Kiến trúc tổng thể

flowchart TB
    SSOT[AGENTS.md<br/>SSOT canonical rules] --> CM[CLAUDE.md<br/>Claude Code auto-read]
    SSOT --> CR[".cursor/rules/obsidian-vault.mdc<br/>Cursor alwaysApply"]
    SSOT --> GH[".github/copilot-instructions.md<br/>GitHub Copilot"]
    SSOT --> WS[".windsurfrules<br/>Windsurf/Cascade"]
    SSOT --> CV[CONVENTIONS.md<br/>Aider + generic]
    SSOT --> AC[".aider.conf.yml<br/>Aider config"]
    SSOT -.paste thủ công.-> OC["Obsidian Copilot plugin<br/>system prompt"]
    SSOT -.paste thủ công.-> SC["Smart Composer plugin<br/>system prompt"]
    SSOT -.paste thủ công.-> ChatGPT["ChatGPT / Claude web<br/>custom GPT / Project instructions"]

Files đã tạo ở root vault

FileAI tool tự đọcVai trò
AGENTS.mdCursor (Agent), Codex CLI, OpenAI Codex, Google Jules, Sourcegraph Amp, Factory, Devin, RooCanonical rulebook — chi tiết đầy đủ
CLAUDE.mdClaude Code (Anthropic CLI)Trỏ về AGENTS.md + summary
.cursor/rules/obsidian-vault.mdcCursor (với alwaysApply: true)Tự động inject vào mọi prompt Cursor
.github/copilot-instructions.mdGitHub Copilot (Chat, Edits)Instructions cho Copilot
.windsurfrulesWindsurf / CascadeRules file
CONVENTIONS.mdAider, các agent genericĐược nạp qua .aider.conf.yml
.aider.conf.ymlAiderConfig đọc AGENTS + CONVENTIONS, disable auto-commit

Khi bạn muốn đổi rule: chỉ sửa AGENTS.md. Các file adapter còn lại có tóm tắt nhưng always defer tới AGENTS.md khi conflict — điều này đã được ghi rõ trong từng file.

Verify mọi AI tool đọc được

Test bằng cách mở AI tool và hỏi 1 câu kiểm tra:

ToolCâu hỏi testKỳ vọng
Cursor Chat”What is the frontmatter standard for this vault?”Trả lời theo §3 AGENTS.md
Claude Code”Where should I put a new fleeting note?”00 - Inbox/ theo §2
GitHub Copilot Chat”Create a new literature note for a book”Dùng đúng template + frontmatter
Windsurf”Can I delete this note in 02 - Areas?”Từ chối + giải thích §1.1

Nếu AI không trả lời đúng → kiểm tra file adapter tồn tại và AI đã reload workspace.

AI tool KHÔNG tự đọc file rule (phải cấu hình thủ công)

1. Obsidian Copilot plugin (logancyang)

Plugin này không scan filesystem vault. Cần paste system prompt thủ công 1 lần.

Cách làm:

  1. Mở Obsidian → Settings → Copilot → QA Settings / System Prompt (tên có thể khác giữa các version).
  2. Paste nội dung sau (đã rút gọn từ AGENTS.md):
Bạn là copilot cho vault Obsidian cá nhân của Pham Anh Minh (Smart Second Brain, PARA+). 
Tuân thủ nghiêm ngặt các rule sau cho mọi thao tác tạo/sửa/tóm tắt note:

NEVER:
- Xoá/rename note trong 02 - Areas/, 03 - Resources/, 05 - MOCs/, 06 - Journal/, 07 - Literature/ khi không được yêu cầu tường minh.
- Copy-paste nguyên văn từ nguồn ngoài vào literature note. Phải viết lại bằng tiếng Việt, lời của user.
- Tự tạo folder top-level mới ngoài cấu trúc PARA+.
- Đổi tên file có ký tự tiếng Việt thành ASCII.

ALWAYS:
- Frontmatter chuẩn cho note mới:
  title, aliases, created (YYYY-MM-DD), updated (YYYY-MM-DD), 
  status (fleeting|literature|atomic|evergreen|draft|published),
  type (note|book|article|video|course|project|moc|idea|daily|weekly|monthly),
  domain (list), source, tags (list).
- Update "updated" về ngày hôm nay khi edit.
- Wikilinks [[Title]] cho link nội bộ, không markdown link.
- Tiếng Việt cho nội dung cá nhân; giữ thuật ngữ gốc cho technical (Pod, Smartscape, PurePath, DQL...).
- Bullet-first, ngắn gọn, không lạm dụng emoji.

Folder semantics:
- 00 - Inbox: fleeting chưa phân loại
- 01 - Projects: có deadline
- 02 - Areas: dài hạn (K8S, Docker, Observability, Dynatrace)
- 03 - Resources: tham khảo evergreen
- 04 - Archive: đã xong
- 05 - MOCs: index chủ đề
- 06 - Journal: Daily/Weekly/Monthly
- 07 - Literature: Books/Articles

Tag taxonomy 3 trục:
- #status/fleeting|literature|atomic|evergreen|draft|published
- #type/note|book|article|video|course|project|moc|idea
- #domain/devops|k8s|docker|linux|networking|observability|dynatrace|datadog|aws|terraform|python|go|security|database|pkm|obsidian|ai|career|personal

Literature notes: phải có section "Takeaway cá nhân" + "Atomic notes sinh ra từ đây".
Atomic notes: 1 ý, 50-300 chữ, ≥2 wikilinks outgoing.

Khi không chắc: dừng và hỏi user 1 câu + 2-3 option. Không đoán bừa.
Rule đầy đủ: xem AGENTS.md ở root vault.
  1. Save. Từ giờ mọi Copilot chat sẽ tự áp dụng rule.

2. Smart Composer / Smart Connections Chat

Nếu dùng plugin khác có field “System prompt” / “Persona” → paste nội dung trên.

3. ChatGPT / Claude web (khi bạn copy-paste vault content sang chat)

  • Custom GPT (ChatGPT Plus): tạo 1 GPT tên “Obsidian Vault Assistant”, paste system prompt ở trên.
  • Claude Project: tạo Project, paste instructions. Upload AGENTS.md vào Project Knowledge.
  • Gemini Gems: tạo Gem với instruction tương tự.

4. Obsidian Web Clipper (khi clip bài viết)

Plugin này không có AI. Nhưng bạn có thể set template clip để tự chèn frontmatter chuẩn. Trong Settings của extension:

  • Default note location: 00 - Inbox/
  • Note property template:

Khi rule cần update

  1. Sửa chỉ AGENTS.md.
  2. Check xem có cần update summary trong adapter files không (hầu hết các trường hợp không cần — adapter chỉ summary cao).
  3. Với Obsidian Copilot plugin: update system prompt thủ công (paste lại).
  4. Commit theo format: vault: update AI rules — <short reason>.

Sanity check định kỳ (hàng quý)

  • Mở AGENTS.md, đọc xuôi từ đầu, xem có rule nào lỗi thời không.
  • Test 1 câu hỏi mẫu trên Cursor/Claude Code để verify rule đang active.
  • Re-paste system prompt vào Obsidian Copilot sau khi plugin update lớn.
  • Check xem có AI tool mới xuất hiện (vd Amazon Q, Continue.dev) cần thêm adapter không.
