Smart Second Brain Playbook

Hướng dẫn vận hành vault hàng ngày. Đọc cùng Welcome, Frontmatter and Tag Standard, AI Setup - Copilot and Smart Connections, Local AI Setup - Ollama and Lemonade.

1. Triết lý

“Không có nỗi đau nào dễ, nhưng không có nỗi đau thì không đổi.”
— Xây dựng cơ sở dữ liệu cá nhân

Nguyên tắc nền tảng:

  1. Viết dở và đều hơn là viết hay và thưa.
  2. Lời của mình — không copy-paste; diễn đạt lại là tư duy sâu.
  3. Bắt đầu quan trọng hơn hoàn hảo — tránh bẫy cầu toàn.
  4. Hệ thống đơn giản để giải phóng sự chú ý (theo Antigravity VN).
  5. Folder cứng + link động: folder PARA tối thiểu, link/tag/MOC làm lớp động (theo FLOW).
  6. AI là copilot, không phải pilot — AI gợi ý, mình quyết định và viết.

3. Vòng ngày — ~5-10 phút

Sáng (2 phút)

  • Mở Obsidian → mở note đang là trọng tâm (hiện tại: 2026 Certification Roadmap).
  • Ctrl+P → “Open today’s daily note” → template Daily Note tự chèn.
  • Xem lại Inbox & Tasks due soon.

Trong ngày

  • Có ý tưởng? Ctrl+N → note mới auto vào 00 - Inbox/ với template Fleeting Note (Templater: Insert).
  • Đọc bài web hay? Dùng Obsidian Web Clipper extension → clip vào 00 - Inbox/ với status: fleeting, type: article.
  • Highlight sách Kindle? Sync qua plugin Kindle Highlights (hoặc export manual) → 07 - Literature/Books/.

Tối (5 phút, trước khi ngủ) — phần quan trọng nhất

Mở Daily Note hôm nay, trả lời 3 câu hỏi:

  1. Thông tin nào thực sự có giá trị?
  2. Quan điểm cốt lõi là gì?
  3. Áp dụng được vào hoàn cảnh nào của mình?

→ Nếu đáng giữ, tạo fleeting note riêng trong 00 - Inbox/ (Ctrl+P → Templater: Fleeting Note).

4. Vòng tuần — ~30 phút, chiều Chủ nhật

Mở template Weekly Review (Periodic Notes: Open this week’s weekly note):

  1. Đọc lại Daily Notes tuần qua (Dataview tự list).
  2. Xử lý Inbox: với mỗi note → quyết định: move / delete / promote.
    • Fleeting → atomic note (template) nếu ý đã chín.
    • Fleeting từ sách/bài → literature note (template).
    • Không còn giá trị → delete hoặc 04 - Archive/.
  3. Gắn frontmatter + tags theo Frontmatter and Tag Standard (Ctrl+Alt+L để Lint).
  4. Chạy Smart Connections panel trên từng note mới → chấp nhận wikilinks có ý nghĩa.
  5. Copilot: Ctrl+Shift+C → custom prompt “Weekly review generator” (QA mode đọc folder 06 - Journal/Daily/).
  6. Cập nhật MOC liên quan nếu thêm atomic notes quan trọng.
  7. Plan tuần sau: top 3 kết quả muốn đạt + kế hoạch đọc/viết.

5. Vòng tháng — ~60 phút, cuối tháng

Template Monthly Review:

  1. Thống kê Dataview: notes theo folder / status / domain.
  2. Top notes được link nhiều nhất → ứng viên promote lên evergreen.
  3. Atomic >30 ngày, ổn định → đổi status: evergreen.
  4. Fleeting >30 ngày, 0 backlink → prune (delete hoặc archive).
  5. Audit tags (khi vault lớn): Command Palette → Tag Pane → merge tags rác.
  6. Viết Monthly Review bằng Copilot (QA mode đọc các Weekly Review tháng này).

6. Vòng mở rộng domain mới

Khi bạn muốn học 1 lĩnh vực mới (vd AWS, Terraform, Python):

  1. Tạo folder 02 - Areas/<Domain>/ (nếu kiến thức dài hạn) HOẶC 03 - Resources/<Domain>/ (nếu tham khảo).
  2. Tạo 05 - MOCs/MOC - <Domain>.md từ template MOC.
  3. Thêm domain: <domain> vào Frontmatter and Tag Standard §4.
  4. Bắt đầu capture → process → connect như bình thường.
  5. Sau 20+ notes trong domain → review MOC, tạo sub-MOCs nếu cần.

7. Cheat sheet — Copilot prompts thường dùng

Đã lưu trong AI Setup - Copilot and Smart Connections §6:

  • Rewrite in my own words — paste đoạn trích, AI viết lại bằng lời mình.
  • Atomic notes từ literature — cho 1 literature note, sinh 3-5 atomic.
  • Weekly review generator — đọc Daily Notes tuần → weekly review.
  • 3 câu hỏi phản tư — cho fleeting note, AI đặt 3 câu + trả lời bằng lời mình.

Thêm prompts tuỳ domain:

  • “Giải thích DQL query sau cho người mới”
  • “Tìm inconsistency giữa 2 notes về K8S scheduling”
  • “Nêu 3 điểm yếu trong argument này”

Tạo folder sâu >3 cấpNote bị “ẩn”, khó tìmDùng MOC + tag thay vì nested folder
Nhồi hết thông tin vào 1 note khổng lồKhông tái sử dụng đượcTách atomic notes

Bỏ qua weekly reviewInbox phình to → paralysisBlock lịch cố định chiều CN
Dùng AI để sinh content thay vì tóm tắtNội dung nông, không phải của mìnhAI chỉ gợi ý + rewrite, mình viết bản cuối
Tối ưu hoá setup thay vì viếtBẫy hoàn hảoViết trước, fix setup khi đau thật sự

9. Health check hàng quý

  • Graph view còn kết nối? (cluster cô lập → thiếu MOC/link).
  • Số atomic notes tăng so với quý trước?
  • Tỉ lệ fleeting:atomic:evergreen = ~60:30:10 (healthy).
  • Inbox < 20 notes khi weekend bắt đầu?
  • Copilot + Smart Connections còn hoạt động (re-index nếu cần)?
  • Git backup 100% thành công trong 90 ngày qua?

10. Đường nâng cấp dài hạn (3-6-12 tháng)

  • Month 1-3: Quen workflow, đạt fleeting:atomic:evergreen = 70:25:5.
  • Month 3-6: Publish 1 bài/tháng lấy từ atomic notes. Đánh giá Gemini Flash — xem §AI Setup §8.
  • Month 6-12: Cân nhắc build Personal API (export notes → RAG endpoint, hỏi từ ngoài Obsidian). Publish dưới dạng digital garden nếu muốn chia sẻ.
  • Year 2: Tỉ lệ evergreen ≥20% → chính thức có “bộ não thứ hai” đủ rộng để tra cứu thay Google trong domain quen.

11. AI stack hiện tại & khi nào dùng gì

Primary approach (2026-04-20): external IDE-class agent (Cursor / Codex / Antigravity) mở folder d:\Obsidian\. Chi tiết: External AI Agents - Cursor Codex Antigravity.

Tình huốngToolModel
Viết/chỉnh note, refactor, multi-step editCursor / Codex / AntigravityModel mặc định của agent (Claude Opus 4.6 / GPT-5.4 / Gemini 3 Pro)
Semantic “related notes” trong ObsidianSmart Connections pluginnomic-embed-text (local, qua Ollama) hoặc fallback transformers.js
Nội dung #private, #personal, hoặc 06 - Journal/External agent với privacy mode ON + local-only processingKhông gửi raw ra cloud; nếu cần local chat → bật lại Ollama
Offline hoàn toàn / no internetObsidian Copilot plugin (re-enable)qwen-fast (Ollama local, ~10 tok/s)
Test/benchmark model localOllama CLIqwen-fast, gemma4:e4b, llama3.2:3b

Deferred (bật lại khi cần)

  • Ollama server (installed, auto-start disabled). Models trên D:\AI\models\ollama\.
  • Copilot plugin (installed, disabled trong .obsidian/community-plugins.json).
  • Recovery nhanh: Local AI Setup - Ollama and Lemonade §Recovery.

Smart Connections vẫn cần Ollama chạy cho embedding nomic-embed-text. Nếu Ollama tắt lâu, chuyển Smart Connections sang provider transformers.js (chạy in-browser, chậm hơn 3-5× nhưng không cần server).
