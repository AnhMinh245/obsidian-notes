AI Setup: Smart Connections (primary) + Copilot plugin (deferred)

⚠️ CẬP NHẬT 2026-04-20 — primary in-vault AI approach:

  • Chat / edit / agent task: dùng external agents (Cursor / Codex / Antigravity) mở folder vault — xem External AI Agents - Cursor Codex Antigravity.
  • In-vault semantic search “related notes”: Smart Connections plugin (phần §5 ở dưới) — vẫn giữ, đây là công cụ navigation không thay thế được.
  • Copilot plugin (phần §1, §2, §3, §4, §6-9) — tạm DEFER. Plugin bị disable, API key vẫn còn trong data.json (gitignored) phòng khi bật lại.

File này giờ giữ 2 role: (a) Doc primary cho Smart Connections setup, (b) Reference cho Copilot plugin khi bật lại sau này.

0. Tổng quan kiến trúc (primary = external agent)

flowchart LR
    User[You] --> Agents["External Agents<br/>(Cursor / Codex / Antigravity)"]

    Agents -->|read/write/edit| Vault[("d:\\Obsidian vault")]
    Agents -->|chat/agent| CloudAI["Claude Opus 4.6<br/>GPT-5.4 / Gemini 3 Pro"]

  • Daily driver: external agent + Smart Connections (không cần chat UI trong Obsidian).
  • Smart Connections embedding: local qua Ollama nomic-embed-text → cần Ollama chạy cho phần này. Nếu Ollama tắt: Smart Connections fallback transformers.js (chạy trong browser, chậm hơn nhưng không cần server).

🟢 PART A — Smart Connections (PRIMARY, vẫn active)

A.1. Cài plugin

Settings → Community plugins → Browse → tìm Smart Connections (author: Brian Petro) → Install + Enable. ID plugin: smart-connections.

A.2. Cấu hình embedding local

Settings → Smart Connections:

  • Embedding model provider: Ollama
  • Endpoint URL: http://localhost:11434
  • Model: nomic-embed-text
  • Dimensions: 768 (auto từ model)
  • Excluded folders: 04 - Archive, Attachments, Excalidraw, Templates, copilot, .obsidian
  • Smart View: enable → panel sidebar tự hiện related notes khi mở note

A.3. Build embeddings lần đầu

Yêu cầu Ollama chạy (nếu đã stop theo recovery instructions ở Local AI Setup - Ollama and Lemonade):

Trong Obsidian: Command Palette → “Smart Connections: Rebuild smart blocks” (5-30 phút tuỳ vault size).

A.4. Fallback nếu không muốn chạy Ollama

Smart Connections có option transformers.js — model chạy in-browser, không cần server:

  • Settings → Smart Connections → Embedding model provider → transformers.js
  • Model: TaylorAI/bge-micro-v2 (mặc định, ~30 MB)
  • Chậm hơn Ollama ~3-5×, nhưng không phụ thuộc server nào.

Khuyến nghị: dùng Ollama local (A.2) vì nhanh + chính xác hơn. Chỉ fallback khi chuyển máy / không muốn cài Ollama.

A.5. Backup embeddings

Embeddings DB tại .obsidian/plugins/smart-connections/.smart-env/ — đã exclude trong .gitignore. Khi move vault sang máy mới chỉ cần rebuild lại (~10-30 phút).

🟡 PART B — Copilot plugin (DEFERRED, giữ làm reference)

Phần dưới đây giữ nguyên cho trường hợp bật lại Copilot plugin sau này. Hiện tại plugin đã được disable trong .obsidian/community-plugins.json.

Khi nào bật lại:

  • Offline hoàn toàn, không có cách gọi external agent.
  • Muốn test custom prompts trực tiếp trong Obsidian UI.
  • Copilot plugin release fix cho streaming bug đã gặp 2026-04-20 (“Failed to parse stream”).

B.1. Lấy API keys miễn phí

1.1. Gemini (Google AI Studio)

  1. Vào https://aistudio.google.com/apikey
  2. Đăng nhập Google → Create API Key → chọn Google Cloud project (hoặc tạo mới).
  3. Copy key. Lưu tạm trong 1Password/Bitwarden hoặc file .env ngoài vault.

Free tier (2026):

  • Gemini 2.5 Flash: ~15 requests/minute, 1,000 requests/day, 1M token context.
  • Đủ cho daily use (~50-200 request/ngày).

1.2. Groq (Llama 3.3 / Mixtral)

  1. Vào https://console.groq.com/keys
  2. Sign up (email hoặc GitHub) → Create API Key.
  3. Copy key.

Free tier: 30 requests/minute, 14,400 requests/day. Model khuyên dùng: llama-3.3-70b-versatile (nhanh, chất lượng tốt cho tóm tắt).

1.3. (Tuỳ chọn) OpenRouter

https://openrouter.ai/keys — có nhiều model free hoặc rất rẻ. Key này phòng khi Gemini/Groq bị rate limit.

Phần này chỉ quick-start. Hướng dẫn đầy đủ cho dualboot Windows 11 + Fedora (share model cache qua D:\AI\models\, ROCm/Vulkan cho 780M, Lemonade-NPU, benchmark script) → xem Local AI Setup - Ollama and Lemonade.

3. Cài 2 plugin AI trong Obsidian

Settings → Community plugins → Browse → tìm và Install + Enable:

  1. Copilot (tác giả: logancyang). ID: copilot.
  2. Smart Connections (tác giả: Brian Petro). ID: smart-connections.

4. Cấu hình Copilot

Settings → Copilot (plugin settings):

General

  • Default model: GEMINI-2.5-FLASH (chọn Model Provider = Gemini).
  • Embedding model: Ollama - nomic-embed-text.
  • QA Mode: enable.
  • QA Exclusions: 04 - Archive/**, Attachments/**, Excalidraw/**, .obsidian/**.

Custom models (offline / privacy mode) — cập nhật 2026-04-20

Vào Copilot Settings → Model → + Add Custom Model:

Tên hiển thịProviderModel nameBase URLKhi dùng
cloud-fastGooglegemini-2.5-flash(default)Có internet, context lớn
local-dailyOllamaqwen2.5:7b-instructhttp://localhost:11434Offline, stable — recommend hiện tại
local-quickOllamallama3.2:3bhttp://localhost:11434Autocomplete ngắn
local-gemma4Ollamagemma4:e4bhttp://localhost:11434⚠️ Chờ Ollama fix (xem Local AI Setup - Ollama and Lemonade §0 pitfall 1)

Embedding model cho Smart Connections + Copilot Vault QA:

  • Add embedding → Provider Ollama, Model nomic-embed-text, Base URL http://localhost:11434
  • Dimension: 768
  • Mặc định model này khi enable Vault QA → privacy 100% (không gửi vault ra cloud).

Swap model chat bằng dropdown ở header Copilot Chat hoặc Command Palette: Copilot: Select model. Decision flow: xem Local AI Setup - Ollama and Lemonade §6.

Quan trọng: các API key (Gemini, Groq) được plugin lưu trong .obsidian/plugins/copilot/data.json — file này đã được exclude trong .gitignore vault root. Nếu bạn từng commit nhầm, rotate key tại https://aistudio.google.com/apikey và https://console.groq.com/keys.

API Keys (tab API)

  • Google: paste Gemini API key.
  • Groq: paste Groq API key (optional, cho chat alternative).
  • Ollama base URL: http://localhost:11434 (mặc định).

Chat Settings

  • Temperature: 0.3 (tóm tắt), 0.7 (viết sáng tạo) — dùng 2 preset model.
  • Max tokens: 2048.
  • Include active note in context: on.

Indexing

  • Index Vault: chạy lần đầu sau khi cấu hình xong. Tốn vài phút (tuỳ vault size) và sẽ tạo embeddings database.
  • Re-index tự động: Daily (config trong plugin).

Hotkeys gợi ý

  • Ctrl+P → “Copilot: Toggle Copilot Chat Window”.
  • Gán Ctrl+Shift+C để mở chat nhanh.
  • Gán Ctrl+Shift+A để “Copilot: Apply custom prompt to selection”.

5. Cấu hình Smart Connections

📌 Đã move lên Part A ở đầu file — Smart Connections là primary tool, không còn là sub-section của Copilot setup. Xem §A.1-A.5 ở trên.

6. Custom prompts cho Copilot (paste vào plugin settings → Custom Prompts)

Prompt 1 — “Rewrite in my own words”

Bạn là copilot viết lách. Đọc đoạn văn sau và viết lại bằng lời của chính người đọc,
giữ nguyên ý chính nhưng không copy cấu trúc câu. Kết quả bằng tiếng Việt,
phong cách ngắn gọn, rõ ràng, dễ nhớ. Không thêm thông tin mới.

<text>
{selection}
</text>

Prompt 2 — “Atomic note từ literature”

Từ literature note dưới đây, tạo ra 3-5 atomic notes riêng biệt.
Mỗi atomic note gồm:
- Một ý chính duy nhất (1 câu khẳng định)
- 2-3 câu giải thích
- Đề xuất 2-3 [[wikilinks]] đến các concept liên quan
- Frontmatter với status: atomic, type: note, domain tương ứng

<literature>
{activeNote}
</literature>

Prompt 3 — “Weekly review generator”

Tổng hợp Weekly Review từ các Daily Notes của tuần này (đã nạp qua QA Mode).
Trả về theo format:
1. Đã đọc / học gì (bullet)
2. 3 insight quan trọng nhất (đoạn ngắn + link note)
3. Link giữa các concept rời rạc (gợi ý wikilinks mới)
4. Câu hỏi mở cho tuần sau
Ngôn ngữ: tiếng Việt, ngắn gọn.

Prompt 4 — “3 câu hỏi phản tư”

Đọc nội dung fleeting note dưới đây và trả lời giúp:
1. Thông tin nào thực sự có giá trị?
2. Quan điểm cốt lõi là gì?
3. Áp dụng được vào hoàn cảnh nào của mình?

Trả lời bằng tiếng Việt, 1-2 câu mỗi ý, bằng lời của người viết (chủ động hoá).

<note>
{activeNote}
</note>

7. Test plan sau cài đặt

  • Copilot chat trả lời bình thường khi hỏi câu chung.
  • Copilot QA mode trả lời được câu “Tóm tắt Dynatrace DQL trong vault” sau khi index.
  • Smart Connections panel hiển thị notes liên quan khi mở 1 note trong 02 - Areas/Observability.
  • Ollama phản hồi tại http://localhost:11434 (check status bar Copilot).
  • Gemini key chưa hết quota sau 1 ngày dùng bình thường.

8. Tiêu chí nâng cấp paid tier

Chỉ nâng cấp khi cả 2 điều kiện xảy ra trong 1 tháng:

  1. Gemini Flash trả lời hời hợt / sai ở nhiệm vụ quan trọng (weekly review, synthesis nhiều nguồn).
  2. Bạn đã dùng AI tối thiểu 3 lần/tuần, thực sự cần lên level.

Lộ trình nâng cấp:

  • Step 1: OpenRouter (pay-per-token) với anthropic/claude-3.5-haiku (~0.8/Minput)—chiphıˊ<2/tháng cho mức dùng trung bình.
  • Step 2: Claude Sonnet hoặc GPT-4o qua direct API (~$3-5/M input) — khi cần reasoning sâu.
  • Step 3: Claude/ChatGPT subscription $20/tháng — chỉ khi dùng hàng ngày thay thế hẳn ChatGPT.

9. Backup & privacy

  • Embeddings DB của Smart Connections lưu tại .obsidian/plugins/smart-connections/.smart-env/ — đã exclude trong .gitignore.
  • Copilot index lưu tại .obsidian/plugins/copilot/ (data file) — cũng exclude nếu lớn.
  • Với notes nhạy cảm (tài chính, mật khẩu, nhật ký cá nhân sâu): gắn tag #private, thêm folder chứa chúng vào QA Exclusions Copilot, và dùng preset local-daily / local-reason (Gemma 4 Ollama) thay vì Gemini. Nội dung không ra khỏi máy.
  • Model local store: D:\AI\models\ollama (chia sẻ Windows + Fedora). Đã exclude trong .gitignore vault root (xem Local AI Setup - Ollama and Lemonade).
