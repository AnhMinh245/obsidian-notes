Frontmatter & Tag Standard

Tài liệu tham chiếu cho mọi note trong vault. Tuân thủ để Dataview query, Smart Connections embedding, và Copilot QA hoạt động chính xác.

1. Frontmatter chuẩn

Áp dụng cho note mới; retrofit dần cho note cũ khi đụng đến.

Giải thích từng field

FieldBắt buộcGiá trị hợp lệGhi chú
titleCóTên hiển thị của noteCó thể khác tên file để dễ tìm kiếm
aliasesKhôngList stringDùng cho auto-complete [[link]]
createdCóYYYY-MM-DDLinter tự điền từ file system
updatedCóYYYY-MM-DDLinter tự cập nhật khi lint
statusCóxem §2Workflow trạng thái note

2. Trục status (vòng đời note)

flowchart LR
    F[fleeting] --> L[literature]
    F --> A[atomic]
    L --> A
    A --> E[evergreen]
    A --> D[draft]
    D --> P[published]
    E --> D
  • fleeting: ý nhanh, chưa xử lý. Trong 00 - Inbox/ hoặc Daily Note.
  • literature: tóm tắt nguồn gốc (sách, bài, video) — bằng lời của mình, không copy-paste.
  • atomic: một ý chính, độc lập, tái sử dụng được. Thường trong 02 - Areas/ hoặc 03 - Resources/.
  • evergreen: atomic đã ổn định, tham chiếu lâu dài.
  • draft: đang soạn thành bài/artifact trong 01 - Projects/.
  • published: đã publish ra blog/Substack/repo.

3. Trục type

note (mặc định) | book | article | video | course | project | moc | idea | daily | weekly | monthly

4. Trục domain

Danh sách mở, nhưng cố giữ danh sách tập trung:

devops · k8s · docker · linux · networking · observability · dynatrace · datadog · aws · terraform · python · go · security · database · pkm · obsidian · career · personal

Quy tắc mở rộng: trước khi thêm domain mới, kiểm tra xem có domain cũ nào chứa được không. Nếu phải thêm, cập nhật file này và 05 - MOCs/.

5. Tag taxonomy (3 trục)

Tag là bản sao của frontmatter (cho search nhanh). Luôn flat, tối đa 2 cấp.

TrụcPrefixVí dụ
Trạng thái#status/#status/fleeting, #status/atomic, #status/evergreen
Loại#type/#type/book, #type/article, #type/moc
Lĩnh vực#domain/#domain/k8s, #domain/observability

Tránh tag tự do kiểu #important, #todo (dùng plugin Tasks thay thế), #random.

6. Quy ước đặt tên file

  • Atomic / evergreen: tiêu đề tự giải thích, dạng câu hoàn chỉnh. Ví dụ: Smartscape topology map Dynatrace services.md.
  • Literature: <Author> - <Title>.md hoặc <Title> - <Source>.md.
  • Daily: YYYY-MM-DD.md (đã set qua Core plugin).
  • Weekly: YYYY-Www.md (vd 2026-W17.md).
  • Monthly: YYYY-MM.md.
  • MOC: MOC - <Topic>.md.
  • Project: <Project Name>/00 - Overview.md + các file con đánh số.

7. Linter rules đang bật

Plugin obsidian-linter đã được cấu hình để:

  • insert-yaml-attributes: auto-insert các key chuẩn khi lint note mới.
  • yaml-timestamp: tự ghi created/updated theo file system, định dạng YYYY-MM-DD.
  • format-yaml-array: force tags, aliases, domain dùng multi-line array.

Hotkey gợi ý: Ctrl+Alt+L → “Linter: Lint current file”.
