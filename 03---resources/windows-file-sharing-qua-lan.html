TL;DR

  • Dùng SMB (Server Message Block) — protocol chia sẻ file mặc định trên Windows
  • Máy B (máy backup) → tạo user + share volume E:\ + set quyền
  • Máy A (máy chính) → chạy Robocopy đẩy dữ liệu sang \\IP_MÁY_B\BackupE
  • Yêu cầu: 2 máy cùng mạng LAN (ping được nhau)

1.1. Tạo user dùng để xác thực

Tạo 1 user riêng trên Máy B cho việc share file (không nên dùng tài khoản chính):

Lưu ý: Password phải đủ mạnh nếu máy có bật password policy. Nếu gặp lỗi “password does not meet requirements”, thử password dài hơn có chữ hoa + số + ký tự đặc biệt.

Hoặc tạo qua GUI:

1.2. Bật Network Discovery và File Sharing (trên Máy B)

  1. Mở Control Panel → Network and Sharing Center → Change advanced sharing settings
  2. Trong profile Private (hoặc profile mạng đang dùng):
    • ✅ Turn on network discovery
    • ✅ Turn on file and printer sharing
  3. Cuộn xuống All Networks:
    • ❌ Turn off public folder sharing (không share Public folder)
    • 🔐 Turn on password protected sharing ← BẮT BUỘC để yêu cầu xác thực
  4. Click Save changes

1.3. Chia sẻ folder

  1. Chuột phải vào folder cần share → Properties → tab Sharing
  2. Click Share…
  3. Trong cửa sổ Network access:
    • Gõ tên user vừa tạo (ShareUser) vào ô dropdown → Add
    • Chọn quyền:
      • Read — chỉ xem, copy
      • Read/Write — xem + sửa + xoá + tạo file
    • Click Share → Done
  4. Ghi lại network path hiển thị (vd \\DESKTOP-ABC\SharedFolder)

Hoặc dùng lệnh PowerShell (nhanh hơn):

1.4. Cấu hình NTFS Permission (quan trọng!)

SMB share permission và NTFS permission là 2 lớp riêng biệt — user phải pass cả 2:

  1. Chuột phải folder → Properties → tab Security
  2. Click Edit → Add → gõ ShareUser → Check Names → OK
  3. Tick quyền phù hợp:
    • Read & Execute, List, Read — cho phép đọc
    • Modify — cho phép đọc + ghi + xoá
  4. Click Apply → OK

Giải thích flags:

  • (OI) = Object Inherit — áp dụng cho file con
  • (CI) = Container Inherit — áp dụng cho folder con
  • M = Modify (đọc + ghi + xoá)
  • /T = áp dụng đệ quy

Bước 4 — Backup tự động bằng Robocopy + Task Scheduler

Ví dụ cụ thể

  • Máy A (IP: 192.168.133.132) — máy chính, có volume *E:* chứa dữ liệu làm việc
  • Máy B (IP: 192.168.133.133) — máy backup, có volume *E:* dùng làm nơi nhận backup
  • Máy B share ổ E:\ của mình với tên share là BackupE
  • Máy A chạy script Robocopy → copy dữ liệu từ E:\ local sang \\192.168.133.133\BackupE

Cách 2 — GUI (Task Scheduler)

  1. Win + R → gõ taskschd.msc → Enter
  2. Panel phải → Create Task… (không phải “Create Basic Task”)
  3. Tab General:

    • ☑ Run whether user is logged on or not
    • ☑ Run with highest privileges

  4. Tab Triggers → New…:
    • Begin the task: On a schedule
    • Settings: Daily — Start: 22:00:00

  5. Tab Actions → New…:
    • Action: Start a program
    • Program: powershell.exe
    • Arguments: -NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\backup-to-share.ps1"
  6. Tab Conditions:
    • ☐ Bỏ tick “Start the task only if the computer is on AC power” (nếu laptop)
    • ☑ Start only if the following network connection is available → Any connection
  7. Tab Settings:
    • ☑ Allow task to be run on demand
    • ☑ Run task as soon as possible after a scheduled start is missed
    • ☑ If the task fails, restart every: 5 minutes — Attempt: 3

/MT:8Multi-thread 8 luồngTăng tốc copy nhiều file nhỏ
/R:2Retry 2 lầnMặc định 1,000,000 lần — script sẽ treo!
/W:5Đợi 5s giữa retryMặc định 30s — quá lâu
/NPNo progressGiảm noise trong log file
/XOExclude olderChỉ copy file mới hơn hoặc thay đổi
/XJExclude junctionsTránh vòng lặp symbolic link
/LOG+:fileAppend logGhi tiếp vào log, không ghi đè
/TEETee outputHiện cả console + log
/DCOPY:DATCopy folder metadataGiữ nguyên timestamp folder
/COPY:DATCopy file metadataGiữ nguyên timestamp file

/R:2 và /W:5 là 2 flag quan trọng nhất để script không bị treo khi gặp file bị lock hoặc permission denied. Mặc định Robocopy retry 1 triệu lần, mỗi lần đợi 30 giây — tức là treo vô hạn!

Troubleshooting

Không truy cập được share (network path was not found)

Lỗi Access Denied dù đúng password

  • Kiểm tra cả hai lớp permission trên máy B: SMB share permission + NTFS permission
  • Đảm bảo Password protected sharing đã bật trên máy B
  • Thử dùng format TÊN_MÁY_B\BackupUser thay vì chỉ BackupUser
  • Xoá credential cũ trên máy A (Bước 3) rồi nhập lại

Robocopy báo lỗi nhưng vẫn copy được phần lớn file

  • Exit code 8 = một số file bị skip (thường do đang bị lock bởi app khác)
  • Không cần lo — script đã set /R:2 /W:5 nên sẽ retry 2 lần rồi bỏ qua
  • Lần chạy tiếp theo sẽ copy lại các file bị skip (nếu đã unlock)
  • Xem log để biết chính xác file nào bị lỗi:

Lỗi The specified network password is not correct

  • Kiểm tra lại password (chú ý Caps Lock, bàn phím tiếng Việt)
  • Nếu máy B dùng Microsoft Account, username phải là email đầy đủ hoặc tạo local account riêng

2 máy khác workgroup

Khác workgroup vẫn share được, nhưng cùng workgroup giúp browse dễ hơn trong Network.

SMB version mismatch

Windows 10/11 mặc định dùng SMB 3.x. Nếu máy cũ chỉ hỗ trợ SMB 1.0:

⚠️ SMB1 có lỗ hổng bảo mật nghiêm trọng (WannaCry exploit). Chỉ bật khi thực sự cần thiết và trong mạng nội bộ tin cậy.
